# 編み方の候補調査

日付: 2026-07-29

作者の問い（原文のまま）:

> 別案で編むとどうなるのか考えたい
>
> まずはいろいろな編み方が有ると思うのでパターンをリサーチしてみて

## 最初の区別

日常語ではまとめて「編む」と呼べるが、線の生成規則としては四系統に分けた方がよい。

1. **織る** — 独立した縦糸と横糸を、交点ごとの上下規則で結ぶ
2. **組む** — 複数の線を斜め・螺旋状に入れ替え続ける
3. **編む** — 一本または少数の線でループを作り、次のループを通す
4. **巡る** — 結び目は作らず、一本の連続線で空間を順序よく覆う

現在の `tangle` は4に近い。次の比較では、見た目だけを織物風にせず、
**交差の上下順序、ループの貫通、どの線が連続しているか**を生成規則にする。

## パターン地図

| 系統 | 代表パターン | 線の数 | 形の特徴 | 羊内部への翻訳 |
|---|---|---:|---|---|
| 平織り | plain 1/1 | 多数 | 交差が最多。細かく均質 | 平行な層をx/y方向へ往復し、交点でzを交互にずらす |
| 綾織り | twill 2/1・2/2 | 多数 | 交点が斜めに移り、流れが見える | 上下順を一段ずつずらし、羊の長軸へ斜めの帯を作る |
| 朱子織り | satin | 多数 | 交点が少なく、長い独立区間が残る | 接触を疎にして、長い線と少数の結合点を比較する |
| 二軸ブレイド | ±θの螺旋 | 多数 | 筒を包む菱形網 | 羊の胴・脚の中心線周囲へ左右巻きの螺旋を走らせる |
| 三軸ブレイド | ±θ＋軸方向 | 多数 | 斜線の網へ直線の芯が加わる | 螺旋に頭尾方向の線を加え、輪郭と軸の二重読みを作る |
| ブレイド反復 | diamond 1/1 / regular 2/2 / Hercules 3/3 | 多数 | 一本が何本越えてから潜るかが変わる | 交差周期を1・2・3で比較し、穴の大きさと線の追いやすさを見る |
| 3D直交織り | x/y/z yarn | 多数 | 三方向の格子。内部まで均質 | ボクセル行列を三方向に貫き、境界で折り返す |
| 角度インターロック | layer-to-layer / through-thickness | 多数 | 層を斜めの結合糸が縫う | 輪郭に沿う層を作り、隣接層を斜めの線で結ぶ |
| 緯編み | knit / purl | 一本可 | 一列のループを次の列が保持する | 断面ごとにループ列を作り、前断面のループを次がくぐる |
| 変化編み | tuck / miss / cable / lace | 一本可 | 保持、飛ばし、交差で穴と盛上がりが変わる | ループを保持／飛越し／入替えし、疎密と穴を意図的に作る |
| 立体編み | solid knitting | 一本または少数 | course・wale・layerの三方向で体積を結ぶ | 3Dセルの各ループを前の列と前の層へ同時に通す |
| 空間充填曲線 | 3D Hilbert / Peano | 一本 | 自己相似で隣接セルを順に巡る | 羊内部ボクセルを階層分割し、隣接セル順を連続線へする |

## 研究から分かったこと

- 織物の基本三種は plain / twill / satin。違いは主に交差の頻度と反復順序であり、
  表面模様だけではない
- 円形ブレイドは各線が螺旋を描く管状構造。diamond 1/1、regular 2/2、
  Hercules 3/3という「何本越えてから潜るか」の反復がある。三軸型はさらに軸方向線を持つ
- 3D織物は、平面布を厚くしただけでなく、直交、layer-to-layer、angle-interlockなど、
  厚み方向の結合糸を第一級に持つ
- 編み物は一本の糸で成立しやすいが、自己接触を避けるだけでは成立しない。
  ループが前のループを**くぐって保持する**トポロジーが必要
- Solid Knitting は層状3Dプリントに似た進行で、各ループを前のcourseと前のlayerの
  両方へ通し、表面でなく体積を編む。今回の「一本で羊内部を満たす」に最も近い既存研究
- 3D Hilbert曲線は編み物ではないが、一本線・連続・空間被覆という条件の比較基準になる。
  3D版は一種類ではなく、局所性や端点条件の違う多数の変種がある

## Katachiで最初に並べる候補

### A. ループ編み — 一本・表面から内部へ

断面列にループを並べ、次の断面の一本が前のループをくぐる。
現在の有機的な軌跡と最も違いが見え、一本が自分自身と交差せずに「結ばれる」。
操作候補は `ループ幅 / 段間隔 / knit-purl反転 / 飛ばす割合`。

### B. 管状ブレイド — 複数線・身体の軸に沿う

羊を胴・脚・頭の中心線を持つ管の集合として読み、±θの螺旋で包む。
diamond / regular / Hercules と、二軸／三軸を比較する。
現在のランダムな絡まりに対し、身体方向が読める規則的な別案になる。

### C. 3D直交／角度インターロック — 複数線・体積格子

x/y/zの直交線と、層を斜めに縫う線を比較する。
充填率は上げやすいが、最も人工的・設計的に見える可能性がある。
現在の生成された軌跡との対照群として重要。

### D. 3D Hilbert — 一本・結ばずに巡る基準

羊内部のセルを階層的に並べ、一本で隣接セルを巡る。
「編まなくても一本で均質に満たせる」基準にし、ループ編みの穴や偏りが
どこから生まれるかを分離する。

## 実装順の提案

最初の比較は **現在の有機軌跡 / ループ編み / 管状ブレイド / 3D Hilbert** の四者。
直交・角度インターロックは、羊を格子へ写す方法が四者より重いため第二便に回す。

人間の判断ポイント:

- 一本を目で最後まで追えるか
- 穴が「充填不足」ではなく、編み目として読めるか
- 羊の身体方向が残るか、編み規則が羊を上書きするか
- 規則性が強い方が面白いか、有機軌跡との間に中間が必要か
