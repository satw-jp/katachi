# 羊に原理を作用させる (Hitsuji Principles)

## Question

作者自身がすでに形にした同じ羊へ、差分成長・相分離・流れという異なる原理を作用させたとき、
どこまで元の羊の同一性が残り、どこから別の形になり始めるか。

## Setup

- 共通入力: 作者の `fuwafuwa / hitsuji_260304.glb`
- 比較: 加工前／差分成長の素描／相分離の素描／流れに沿う羊毛化の素描
- 4者は同じ頂点列、同じ尺度、同じカメラで表示する
- 別画面「現象を見る」では、形状へ変換する前の3D相分離場を霧・点・断面で観察する
- Seed は共通だが、操作は原理ごとに分ける:
  - 差分成長: `成長量 / 成長域の細かさ / 成長差 / 表面のむら`
  - 相分離: `穴の量 / 相の大きさ / まとまりの時間 / 外側への膨らみ / 内側への厚み`
  - 流れに沿う羊毛化: `毛束の高さ / 毛束の密度 / 流れの曲がり / 稜線の細さ`

「差分成長」は低周波の成長量の差を表面の膨らみへ翻訳する。
「相分離」は3D格子上の二相の粗大化（Allen–Cahn 型の素描）を羊の表面へ写し、
片方の相に属する面を除いて**実際の開口**にする。残る面は外側へ膨らませ、複製した内面を
内側へ下げ、穴の縁で両者を接続して殻にする。ただし羊の体積内で相分離して抽出した
多孔質体ではなく、表面相分離へ後から厚みを加えた段階である。
「流れに沿う羊毛化」は方向が曲がる場に沿った細い稜線を表面の盛り上がりへ写す。
いずれも、現時点では現実の物理を解いたものでも、印刷可能性を保証するものでもない。

## 問答

### 2026-07-28 — 相分離は根本的に間違っていなかったか

**作者:** 「相分離は見せてくれたみたいに穴が空いていないのでこれだけ根本的に間違っていないか確認してほしい」

**確認結果:** 見せた候補の意味に対しては根本的に違っていた。二相に分かれる値を
「どこが膨らむか」へ使っていたが、必要だったのは「どちらの相を物質として残し、
どちらを空隙として抜くか」だった。v0.2 はまず表面の面を実際に抜くところまで直した。
ただし、これはまだ厚みのない表面相分離である。見せた案のような空気を抱く多孔質体へ進むには、
羊の内外を含む**体積場で二相を作り、片方の相の境界を閉じたメッシュとして再抽出する**必要がある。

### 2026-07-28 — 相分離は n 分と考えられるか

**作者:** 「羊毛化の密度をもっとあげられるようにしたい」

**作者:** 「相分離って今２分だけどn分って考えられるの？」

**答え:** 考えられる。今の二相分離は、各場所が二つの安定した状態のどちらへ寄るかを
一つの値で表している。n相では、n個の候補が場所を取り合い、各場所がそのうち一つへ属する
ようにすればよい。ただし、n相にしただけでは穴の意味は決まらない。単一素材の羊では、
たとえば「1相を物質、残りを穴にする」「複数相を物質として残す」「相ごとに別素材として見せる」
という異なる読み方がある。まず n=2 / 3 / 4 を並べ、**何相を残すか**も変えて、
穴の連結・断片化・羊の同一性がどう変わるかを見るのが次の比較になる。

### 2026-07-28 — 同じ操作は Blender でもできるか

**作者:** 「こういう操作ってblenderとかでもできるの？」

**答え:** できる。Geometry Nodes なら、差分成長のような法線変位は位置と場から、
表面相分離の穴は面ごとの場と削除条件から、流れに沿う羊毛化は方向場・曲線・変位から
組める。各値をノードグループの入力に出せば、現在の画面と同じようにスライダーで操作できる。
n相も、複数の場のうち最大のものを相番号として選び、相番号ごとに削除・残存・素材を
切り替えれば表現できる。ただし、現在使っている Allen–Cahn 型の反復計算や、体積場から
閉じた多孔質メッシュを再抽出するところは、標準ノードを少数つなぐだけでは済まない。
Simulation Zone、Volume to Mesh、または Python による専用処理が必要になる。

Katachi は同じ視点で原理差を比較し、Seed・値・観察を研究記録として残す入口に向く。
Blender は、その後の再メッシュ、厚み付け、造形、素材分け、書き出しへ進む場所に向く。
どちらか一方へ置き換えるより、Katachi で方向を選び、選んだ原理を Blender の
Geometry Nodes グループへ移す接続が考えられる。

### 2026-07-28 — 表面へノイズマップを置いて変形しているのか

**作者:** 「僕はRhino+GHまではある程度理解しているけど
今やっている操作って形状表面にノイズマップみたいなものを配置してそこに形状変形操作を
加えているみたいな理解なんだけどどう？」

**答え:** 抽象的にはその理解で合っている。現在の基本形は、羊メッシュの各頂点位置 `P` で
空間内の場 `f(P)` を評価し、その値を変形量にして `P' = P + Normal × f(P)` とするもの。
GHでいえば `Mesh Vertices → 各点でFieldをSample → Remap/Graph Mapper相当 →
Vertex Normalとの積 → Move` に近い。

ただし、UVへ貼った2D画像のノイズマップではない。正規化した羊が置かれた3D空間の座標
`x, y, z` から値を計算する、手続き的な3Dスカラー場である。そのためUVの継ぎ目はなく、
同じ空間位置なら同じ値になる。

- 差分成長: fBmノイズから作ったスカラー場を法線変位へ使う。現段階では実際に面を増殖・
  再分割する差分成長ではなく、「成長量の場所差」の素描。
- 流れに沿う羊毛化: 曲げた座標に方向性のある波を作り、その稜線を法線変位へ使う。
  現段階では頂点がベクトル場を流れるのでも、独立した毛束が生えるのでもない。
- 相分離: ここだけは単純なノイズではなく、3D格子上で二相場を34回反復して粗大化させる。
  その場を羊の頂点でSampleし、三角形の平均値がしきい値より低ければ面を削除し、
  残した側だけ少し法線方向へ膨らませる。

したがって現在は、三つの完成した物理現象というより、**異なる場の作り方と、その場を
羊の表面へどう作用させるかの比較**である。形の更新操作は主に法線変位で共通しており、
相分離だけが面の削除を追加している。

### 2026-07-28 — 相分離の厚みと、三種類の場を理解したい

**作者:** 「羊の体積化 → 体積内で相分離 → 残す相を決定 → Volume to Mesh
これ興味がある
あと今相分離って厚みがないので残る相の膨らみをスライドさせたとき元の形状＋残る相の膨らみで
厚みができるべきだと思った。残る相の膨らみ（内側）も必要なのでは

3Dノイズ場
方向性のある波
二つの領域がまとまっていく場
このあたりは僕の理解を超えているので理解できるように図示とかステップを作成してほしい」

**答え:** 厚みについての理解はそのとおり。外側へ動かした面だけでは一枚の表面であり、
元形状側の内面と、外面・内面をつなぐ穴の縁が必要になる。v0.3 ではまずこの表面殻を実装した。
ただし本命として作者が興味を示した体積相分離は別の生成方法である。羊の内部をボクセルで満たし、
内部の各セルに相の値を持たせ、時間を進めて領域をまとめ、残す相を二値化し、その境界全体を
等値面としてメッシュ化する。その場合、外表面と内孔面は同じ体積場の境界として同時に生まれ、
後から元表面を複製して厚みを足す必要がない。

三種類の場は、すべて「空間の各場所へ値を割り当てるもの」だが、値の並び方が異なる。

1. 3Dノイズ場: 値が空間内で不規則だが滑らかに変化する。羊の頂点がその空間を横切って値を読む。
2. 方向性のある波: 値の高低が帯として並び、帯の座標を曲げることで流れのような稜線になる。
3. 二つの領域がまとまる場: 最初の細かな混在を反復し、同じ側の値どうしが大きな領域へまとまる。

共通の三段階は「場をつくる → 羊の表面または体積で値を読む → 値を形状操作へ変換する」。
理解用の図では、三種類を切り替えながらこの三段階を追えるようにした。

### 2026-07-28 — 各段階を自分で操作できるか

**作者:** 「それぞれの段階で僕が操作できるようにできる？」

**答え:** できる。理解図を、段階を読むだけの図から、段階ごとに異なる値を操作する実験へ更新した。

1. 場をつくる: `場の細かさ`と、ノイズの`むらの重なり`／波の`流れの曲がり`／
   相分離の`まとまりの時間`
2. 表面で読む: `読む点の数`と、`取り出す値の境界`または`残す相の境界`
3. 形へ作用: ノイズの`膨らみ・成長差`／波の`毛束の高さ・稜線の細さ`／
   相分離の`外側への膨らみ・内側への厚み`

これにより、同じ最終形のパラメータとして値を並べるのではなく、**どの段階を変えた結果として
形が変わったか**を区別して観察できる。

### 2026-07-28 — 理解図から3Dへ移行する

**作者:** 「では3Dに移行して」

**答え:** 理解図の三段階を、実際の3D羊を変形する操作へ移した。

- 差分成長: 場=`成長域の細かさ・表面のむら`／読取=`成長差`／作用=`成長量`
- 相分離: 場=`相の大きさ・まとまりの時間`／読取=`穴の量`／
  作用=`外側への膨らみ・内側への厚み`
- 流れに沿う羊毛化: 場=`毛束の密度・流れの曲がり`／読取=`稜線の細さ`／
  作用=`毛束の高さ`

相分離の「まとまりの時間」は説明用の見せ方ではなく、3D格子の反復回数そのもの。
0では初期の細かな混在、80へ近づくほど同じ側の値がまとまった場になる。ただし、羊内部を
ボクセル化して境界を再抽出する体積相分離ではなく、現時点ではその3D場を羊の表面で読む段階である。

### 2026-07-28 — 形状になる前に現象として考えられるか

**作者:** 「今ってなんとなく形状に固執しているけれど雲みたいに現象化させてから考えるってのも
ありなのかなとも思う」

**答え:** あり得る。現在は「完成した羊の表面へ場を作用させ、別の形状を得る」という
**形状先行**の流れである。そのため毎回、頂点をどう動かすか、面をどう削るか、厚みをどう作るか
というメッシュ操作へ思考が戻っている。

雲のように考える場合、主役はメッシュではなく、空間内で時間変化する密度・相・流れになる。
まず現象を点・霧・断面・透明度として観察し、その後で必要なら、ある密度以上の境界を一時的な
形状として取り出す。このときメッシュは完成形ではなく、現象を見るための一つの観測方法になる。

考えられる三つの入口:

1. **形状 → 現象**: 現在の羊表面へ場を作用させる
2. **現象 → 形状**: 空間内で現象を育て、後から境界を取り出す
3. **形状を現象の条件にする**: 羊を完成形ではなく、発生範囲・障害物・初期密度として使う

三つ目なら、羊への固執と羊の放棄の中間になる。羊は最終輪郭を強制せず、現象が始まる条件だけを
与える。作者が次に見るべき差は、美しいメッシュが得られるかではなく、羊の輪郭を外しても
なお興味を感じる現象があるか、そして現象から再び形を取り出したくなる瞬間があるかである。

### 2026-07-28 — 現在の形状比較を残して現象表示を実装する

**作者:** 「今のものは残して君の提案を実装してみて」

**実装:** 既存の `hitsuji.html` は4者比較として残し、`hitsuji-field.html` を
「相分離を現象として見る」画面として追加した。初期表示は羊を使わず、相Aの高密度部分を
半透明な3D霧として見る。観察者は、霧・点・断面、見る相、密度境界、まとまりの時間を変えられる。
必要になったときだけ羊を透明ワイヤーとして重ねられるが、羊は相分離場を切り抜くマスクではなく、
まだ単なる比較参照である。ここではVolume to Meshも形状保存も行わない。

### 2026-07-28 — 羊を表示した先に何があるか

**作者:** 「hitsujiを表示したところでどうなるのかわからない
切り取るの？それ以外も色々ありそうだね
君の提案を見せて」

**答え:** 透明な羊を重ねるだけでは、現象との位置関係を見比べられるだけで、現象には何も
起こらない。「羊をどう使うか」は別の選択として扱う必要がある。v0.6では次の5関係を並べた。

1. **羊を使わない:** 空間内の相分離をそのまま見る基準。
2. **透明な参照だけ:** 現象は変えず、羊の位置と尺度だけを見比べる。
3. **羊の内側で起こす:** 羊の内側にある点だけを残す。「切り取る」に相当する。
4. **羊を空洞として避ける:** 羊の内側を除き、現象を外側へ残す。羊を障害物・空隙として読む。
5. **羊の表面から発生:** 表面近くの帯だけを残す。羊の輪郭を、最終形ではなく発生場所として読む。

ただし3〜5も、現時点では先に計算した相分離場を羊の条件で**後から選別している**。
「表面から発生」という名前でも、表面を初期密度にして相が内外へ育っているわけではない。
次の本質的な比較は、同じ5関係のうち発生範囲・障害物・表面源を相分離計算の
初期条件／境界条件へ入れ、後処理の切り取りと時間発展の違いを見ることである。

### 2026-07-28 — 羊の条件を時間発展へ入れる

**作者:** 「すすmてみて」

**実装:** 「効かせる段階」を追加し、前節で次とした比較を実際に操作できるようにした。
「後から選ぶ」は従来どおり完成した相分離場へ羊マスクを掛ける。
「時間発展に入れる」は、各反復の近傍計算へ羊マスクを使う。

- 内側: 羊外を停止し、相は羊内部だけでまとまる
- 外側: 羊内を停止し、相は羊を避けて外側でまとまる
- 表面: 表面帯を相Aの値へ固定し、周囲の場がそこから変化する

これで「羊の形に切った雲」と「羊があったために育ち方が変わった雲」を区別できる。
次の判断点は、表面源が外側だけ／内側だけ／両側へ育つ向きを分けることと、発生源の強さ・
幅・持続時間を操作したとき、羊の輪郭を離れても現象として見続けたい差が生まれるかである。

### 2026-07-28 — 相分離へ風を重ねると何が起こるか

**作者:** 「空洞として避けるっていうのは今のところ可能性を感じないな
ここからさらに視覚化させるのか
風みたいな現象で少し変化を与えてみるとか
どう考えられる」

**答え:** 「空洞として避ける」は羊を障害物にしただけなので、羊の輪郭が負の形として残る。
現時点の像から次の展開が見えないという判断は、その関係を主軸から外す十分な理由になる。

風を加える場合は、表示を派手にするのではなく、相分離の値をベクトル場で運ぶ
**移流**を一段加えると考える。GHでいえば、各ボクセル位置から風ベクトルの逆方向へ一歩戻り、
そこにあった相の値をSampleして現在位置へ運ぶ操作に近い。その後に現在の「同じ相がまとまる」
反復を行う。

`羊の表面から相Aが生まれる → 風が運ぶ → 相Aどうしがまとまる／引き伸ばされる`

という順序なら、羊は完成輪郭でも障害物でもなく、現象の発生場所になる。まず比較したい風は三つ。

1. 一方向の風: 羊から相が尾のように離れる
2. 曲がる風: 羊の周囲を回り込み、渦や巻き込みを作る
3. 脈動する風: 放出と停滞を繰り返し、まとまりが節に分かれる

観察の中心は、風の強さだけでなく、**風に運ばれる速さと相がまとまり直す速さの比**である。
風が勝てば薄く引き伸ばされ、相分離が勝てば塊を保ち、近いときに伸びながらちぎれる境界が現れる
可能性がある。次は一方向の風から始め、風向／移流の強さ／相のまとまりやすさを独立に操作する。

### 2026-07-28 — 一方向の風を実装する

**作者:** 「やってみて」

**実装:** 前節の順序をそのまま3D格子へ入れた。

1. 風の逆方向にあった相の値をSampleして現在位置へ運ぶ
2. 運ばれた場に拡散と二相のまとまり直しを加える
3. 羊の表面源を相Aへ戻し、次の反復へ進む

「風なし」に戻せばv0.7と同じ結果になる。風向を180°反転すると尾も反対側へ移るため、
表示中の点だけを動かしたものではなく、相場そのものが異なる。現在の風は水平な一方向だけで、
曲がり・時間変化・羊表面の局所方向はまだ持たない。

### 2026-07-28 — 曲がる風と脈動する風へ進める

**作者:** 「進めて」

**実装:** 一方向の風を基準に、風向が反復ごとに回転する「曲がる風」と、
風速が停止と最大を周期的に往復する「脈動する風」を追加した。三者は同じ表面源・Seed・
時間・密度境界で切り替えられる。

現24³格子で脈動回数を増やしても、独立した複数の塊へ明瞭に分かれるより、尾の長さと濃淡が
変わる方が先に見えた。脈動を「節」として明確にするには、風を止めるだけでなく表面源の
放出も同期して開閉する比較、または格子解像度を上げる比較が必要になる。

### 2026-07-28 — 点群の密度は変更できるか

**作者:** 「点群の密度って変更できる？」

**答え:** 変更できる。ただし現在の「見える密度」は点の個数を直接変える値ではない。
相の値が指定値より強いボクセルだけを見せる**表示境界**なので、結果的に点数は変わるが、
3D格子自体は常に24³=13,824点である。

区別すべき操作は三つある。

1. **表示する点の割合:** 計算済みのボクセルから何%を描くか。現象は変えず表示だけ疎密になる。
2. **計算格子の解像度:** 24³を32³や48³へ変える。点数だけでなく現象の細かさと計算結果が変わる。
3. **点の大きさ／霧の濃さ:** 点数を変えず、見かけの充填感だけを変える。

まず「表示する点の割合」を独立させれば、同じ相場を疎な点群から密な雲まで観察できる。
格子解像度は再現性と計算時間への影響が大きいため、別の段階として比較する。

**実装:** v0.10で「表示する点の割合」5〜100%を追加した。「見える密度」を変えずに
点群だけを疎密化できる。間引きは毎回ランダムに変わるのではなくSeed付きなので、
同じ条件へ戻せば同じ点群になる。

### 2026-07-28 — ここから形状化まで持っていくか

**作者:** 「ここから形状化まで持っていく？」

**答え:** 持っていく価値がある。現在は、羊の表面から生まれ、風に運ばれ、まとまり直した
3D相場まで到達した。ここで形状化すると、元の羊を変形するのではなく、**現象のある瞬間を
境界面として取り出す**という当初の `Volume to Mesh` を比較できる。

形状化は表示点を球で固める処理ではない。「表示する点の割合」は無視し、24³格子の全相場から
相Aの値が一定値を越える境界をMarching Cubes相当で抽出する。

`表面源 → 風と相分離の時間発展 → 相Aを選ぶ → 境界値を選ぶ → Volume to Mesh`

最初の段階では、既存の霧／点／断面に**境界面**表示を加え、同じSeed・時間・風で往復する。
いきなりSTL保存へ進まず、まず次を観察する。

1. 羊から尾へ、境界面が連続しているか
2. 薄い領域が消え、どの塊が形として残るか
3. 格子端へ到達した尾が切断面になっていないか
4. 24³の角張りが、現象の特徴と区別できるか

相場が計算領域の端へ触れる場合、単純な等値面はそこで開く。外周へ空の1層を加えれば閉じられるが、
それは自然な閉鎖ではなく計算箱による切断でもある。最初の形状化では、この境界条件を隠さず表示する。

**実装:** v0.11で、霧／点／断面と往復できる「境界面」を追加した。表示点の球を結合せず、
24³=13,824ボクセルの全相場から、選んだ相と「見える密度」を等値面として抽出する。
このため「表示する点の割合」は境界面では使われず、点群を25%へ減らしていても形状は変わらない。

Seed 260304、表面源、時間発展、曲がる風180°・強さ0.22・曲がり1.0、まとまり1.0、
相A、密度境界0.30では、点表示25%が817点だった同じ場から2,224三角形の境界面を得た。
羊の塊と風下へ伸びた相は一つの面として連続し、点群では空気として読めた空間が、
形状化すると大きな貫通孔を持つ厚い管状の塊として現れた。外周には相Aが307ボクセル残るため、
面は計算箱で切れており閉じた保存形状ではない。24³由来の段差も輪郭に見える。

## Hypothesis

- 表面相分離の開口だけでは膜の厚みも内部の連続孔も生まれない。体積場で一方の相を固体化したときに初めて、
  羊毛の「空気を抱く体積」へ近づく可能性がある。
- 外面・内面・穴の縁を持つ表面殻は、厚みの理解と操作には役立つが、体積相分離で自然に生まれる
  内部孔の連結とは異なる。両者を並べると「表面へ厚みを足す」と「体積から境界が生まれる」の差を観察できる。
- 羊を最終形ではなく現象の発生範囲・初期条件として使うと、羊の同一性を残しながら
  「現象そのものを先に見る」入口になる可能性がある。
- 表面から生まれた相へ移流を加えると、羊の輪郭を保つ／捨てるの二択ではなく、
  羊を起点に形が離れながら同一性の痕跡を残す過程を観察できる可能性がある。
- 流れに沿う稜線は、羊毛模様を貼るだけではなく輪郭そのものを動かす強さまで上げたとき、
  作者が可能性を感じた「羊毛化」へ近づくかもしれない。
- 差分成長は両者の中間として、元形状の同一性を残したまま表面だけを別の時間へ進める比較軸になりうる。
