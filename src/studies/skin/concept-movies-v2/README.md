# SKIN ART — Concept Movies V2

This route is a separate Presentation Layer exploration of five HANA + SKIN concept movies:

- LUMINOUS CLOUD — point, cloud, and luminous splat density enter the room.
- WAVE BLOOM — local propagation converts points into light, with returns and interference.
- GARDEN IN THE AIR — foreground bloom, midground Gaussian groups, and distant points share depth.
- GATHERING WHITE — white is accumulated luminous overlap; the background remains black.
- WEATHER OF THE BOUQUET — cloud, fog, wind, wave, dappled light, and afterlight behave as one weather.

The renderer reads the same completed `skin-rebuild-first-print.fkei` source as the existing
Studies and Concept Movies routes. It does not modify geometry, FKEI, save/export, or runtime
generation. Since the current FKEI does not contain HANA raw gesture points, temporal and
appearance variation is a deterministic proxy derived from completed Graph edge length,
connectivity, direction change, local density, motif proximity, and support role.

The V1 route remains at `/skin-art/concepts/` and is intentionally not replaced.
