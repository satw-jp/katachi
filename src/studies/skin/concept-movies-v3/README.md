# SKIN ART — Concept V3

`BOUQUET WEATHER` is a single continuous spatial presentation layer. It uses the completed SKIN Graph and FKEI-derived motif data as anchors, then lets points, Gaussian-inspired light, soft lines, cloud, fog, wave propagation and drift occupy one shared 3D field.

The visual source is intentionally presentation-only. V3 does not alter the production geometry, Graph generation, FKEI schema, save/export path or material pipeline. The current FKEI sample has no HANA raw gesture, so appearance variation is a deterministic proxy derived from edge length, connectivity, direction change, local density, motif proximity and support role. The source mapping is isolated in `source.ts` so a future gesture stream can replace it without changing the renderer.

The default route uses a fresh presentation seed. `?seed=12345` makes the spatial arrangement repeatable, while `?palette=rich`, `?palette=red` and `?palette=blue` provide the three comparison palettes.
