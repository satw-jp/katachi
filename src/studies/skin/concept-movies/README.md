# SKIN ART — Concept Movies

This route re-edits the completed SKIN graph into five concept-movie proposals
for the HANA + SKIN bouquet. It is a presentation layer, not a geometry
viewer or a replacement for the ten traversal works.

## Proposals

- `BLOOM SATURATION` — colour and light spill from the bouquet until the room
  approaches white.
- `BREATHING BOUQUET` — asynchronous volume, with `?palette=rich`,
  `?palette=red`, and `?palette=blue` comparison routes.
- `DUST TO LIGHT` — discrete particles gather into anisotropic luminous
  density.
- `LIGHT THROUGH GAPS` — light events are inferred from the spaces between
  the completed structure; the source graph is intentionally almost absent.
- `UNSTABLE BLOOM` — one trace at a time appears, lets go, and returns with a
  persistent afterimage.

The renderer reads the existing completed FKEI through the existing parser.
It derives deterministic appearance signals from edge length, node degree,
direction change, local density, motif proximity, and support role. The source
does not contain HANA Raw Gesture yet, so this bounded proxy is the replacement
point for a future gesture signal. No Graph, FKEI, save, geometry, or export
state is changed.
