# MINIL lower-50 mm component adapter

Issue #66. Scope: isolated CAD candidates using the existing V2 support construction. No native engine, printer connection or source write is present in the adopted entry points.

**Current result: MINIL_LOWZ50_SUPPORT_PROGRAM_HOLD.** The full LIGHT diagnostic produced out-of-bounds parity fill. Its eight trial additions and before/after numbers are quarantined, not validated support improvements. Final code rejects odd scanline crossing counts and caches lacking bounded-section validation. Do not mark the old cache valid or silently close/repair source meshes to bypass this gate.

The initial compact allocation optimization was equivalent for closed contours but not odd-crossing contours. Its legacy-equivalence path now retains the full right tail for odd counts; the LOWZ entry point rejects them. Regression covers both closed and open contours. Cached diagnostics from before this correction are invalid for acceptance.

`construction.py` shares the original capsule shaft, capsule neck and planar foot with `minil/generate.py`. V2 dimensions, mesh tessellation and its original route decisions are unchanged. The new adapter scans every connected section, instead of stopping after a flower contact quota. The section routine is the existing `_section_pixels` implementation.

## Reproducible entry points

Run from the repository root with the pinned Python 3.12 geometry environment (NumPy 2.5.2, scipy 1.18.1, manifold3d 3.5.2, trimesh 5.1.0; lxml and Pillow for import/report).

```text
python -m tools.authored_support.minil.lowz.light --source SOURCE.3mf --sha SOURCE_SHA256 --out NEW_CACHE --zmax 50
python -m tools.authored_support.minil.lowz.reuse --cache NEW_CACHE --out NEW_CANDIDATE --runtime RUNTIME --structural-source STRUCTURAL_SOURCE.json
python -m tools.authored_support.minil.lowz.report --cache NEW_CACHE --out NEW_CANDIDATE
python -m unittest tools.authored_support.minil.lowz.test_reuse -v
python -m tools.authored_support.minil.lowz.replay_check --out NEW_REPLAY_DIRECTORY --runtime RUNTIME
```

Set a writable `TMPDIR` for tests if the Windows sandbox's default temporary directory is inaccessible. Every generation directory must be new. Output NPZ meshes are additions in the saved A1 world XY frame, with CAD Z before raft; **do not import them as independently centered objects**. No assembly is generated by this task.

## What the adapter proves and does not prove

- The input archive is checked against its pinned SHA before and after processing. Every mesh is read with the saved component and build transforms. Source meshes are not repaired, simplified or regenerated.
- Disconnected meshes are sectioned separately, avoiding even/odd cancellation between overlapping parts. Each section's connected components can create new demands, including later petals on one mesh.
- Root propagation reuses the V2 connected-section CAD proxy. Floating sections do not seed future sections. Within-layer extrusion order, native line width and printer raft height remain unknown; lateral CAD continuity is **not native chronology proof**.
- Contact candidates use the existing direct construction with a vertical underside proxy. Full demand raster coverage is required; a single touched point is not sufficient. True surface normals and sub-grid clearances are unverified. No new loft or enlarged receiver is adopted.
- The bounded candidate examines at most 200 eligible demands and adds at most 24 contact routes. It tries the existing direct rule, then the existing rising external branch rule using up to eight nearby frozen plate-rooted shafts. Donor mesh array identities, exact donor intersection and preceding CAD occupancy are checked. All other events and rejection reasons remain recorded. Earlier-BODY surface contact fallback is not connected and cannot be silently counted as solved.
- The finite search is distributed round-robin across 5 mm height bands. It does not spend every attempt near the floor. Detection itself remains exhaustive over the supplied CAD sections; untried events remain listed. Geometry dimensions and acceptance thresholds are not relaxed to obtain a candidate.
- A completed run emits `BEFORE_CACHE_BINDING.json`. `--reuse-before COMPLETED_RUN` reuses its detection only when the source-cache manifest, detection function identity, NumPy version and evidence-file hashes match. Changing precise/light source invalidates it.
- Existing plate-rooted shaft metadata and formal C brace endpoints provide target-side gap audits. Added braces use the original nearest-neighbour, rising-capsule dimensions. These are CAD screening candidates; exact endpoint ownership, lateral vibration, physical buckling and removal remain unverified.
- Counts are **component-sections**, not distinct failed flowers. Aggregated lightweight mesh components are not automatically equivalent to authored flower IDs.
- The recipe is an uncalibrated comparison candidate. `print_go=false` applies only to the new candidate; the Author's current lightweight print continues independently.
