# MINIL lower-50 mm component adapter

Issue #66. Scope: isolated CAD candidates using the existing V2 support construction. No native engine, printer connection or source write is present in the adopted entry points.

**Current task: MINIL_LOWZ50_SECTION_READER_REPAIR.** The old LIGHT cache, eight trial additions and improvement counts remain quarantined. A LOWZ-only closed-ring reader now replaces parity-only source sectioning. See `docs/evidence/MINIL_LOWZ50_SECTION_READER_20261023.md` for the completed real-data audit and remaining HOLD; synthetic tests alone do not establish LIGHT support validity.

The initial compact allocation optimization was equivalent for closed contours but not odd-crossing contours. Its legacy-equivalence path now retains the full right tail for odd counts; the LOWZ entry point rejects them. Regression covers both closed and open contours. Cached diagnostics from before this correction are invalid for acceptance.

`construction.py` shares the original capsule shaft, capsule neck and planar foot with `minil/generate.py`. V2 dimensions, mesh tessellation and its original route decisions are unchanged. The new adapter scans every connected section, instead of stopping after a flower contact quota. The common `_section_pixels` default is unchanged by this repair; only LOWZ uses `section_reader.py`.

## Section contract

- Exact on-plane vertices use their original coordinates. Nonzero segments at or below 1e-8 mm are UNKNOWN, not discarded as empty. Exact point tangencies have no area. Coplanar faces are conservatively UNKNOWN.
- Endpoints weld at 1e-8 mm; duplicate edges, degrees other than two, invalid/self-crossing rings and touching rings are UNKNOWN. No unmatched ends are paired, no source is repaired, and out-of-frame geometry is rejected rather than clipped.
- Closed rings, including nested holes, are filled with even/odd scanlines. Every valid mask is separately checked against GEOS polygon containment; exact-boundary grid centres are explicitly included. Sub-grid polygons may have zero occupied centres, but their positive area remains in the section record.
- UNKNOWN applies to the connected mesh section, not necessarily the entire named flower container. It has `cells=None` in the reader and a separate spatial record in `UNKNOWN_SECTIONS.json`; it is neither supported nor empty. The generator and demand classifier refuse caches with any UNKNOWN. Known-only occupancy must never be interpreted as a complete material mask in that case.
- Fresh manifests bind input SHA before/after, all part hashes, saved placement transforms, raster/phase settings, reader version and file SHA, Shapely/GEOS versions, adapter SHA, validation and UNKNOWN hashes and occupancy SHA. `--reuse-completed` is rejected. Downstream detection identity includes the reader identity.
- The first traced FLOWERS_00 defect (component 189, Z0.66, Y120.67) has ten intersected source edges of incidence 1 or 3, creating three scanline crossings. Coordinate welding does not remove them; no vertex is on the plane. This identifies a source topology cause for that example, not the cause of the running print's physical failure.

## Reproducible entry points

Run from the repository root with the pinned Python 3.12 geometry environment (NumPy 2.5.2, scipy 1.18.1, manifold3d 3.5.2, trimesh 5.1.0; lxml and Pillow for import/report). LOWZ section reading additionally requires Shapely 2.1.2 (`requirements-section-reader.txt`); it is not required by the unchanged V2 generator.

```text
python -m tools.authored_support.minil.lowz.light --source SOURCE.3mf --sha SOURCE_SHA256 --out NEW_CACHE --zmax 50
python -m tools.authored_support.minil.lowz.reuse --cache NEW_CACHE --out NEW_CANDIDATE --runtime RUNTIME --structural-source STRUCTURAL_SOURCE.json
python -m tools.authored_support.minil.lowz.report --cache NEW_CACHE --out NEW_CANDIDATE
python -m unittest tools.authored_support.minil.lowz.test_reuse -v
python -m unittest tools.authored_support.minil.lowz.test_section_reader -v
python -m tools.authored_support.minil.lowz.replay_check --out NEW_REPLAY_DIRECTORY --runtime RUNTIME
```

Set a writable `TMPDIR` for tests if the Windows sandbox's default temporary directory is inaccessible. Every generation directory must be new. Output NPZ meshes are additions in the saved A1 world XY frame, with CAD Z before raft; **do not import them as independently centered objects**. No assembly is generated by this task.

## What the adapter proves and does not prove

- The input archive is checked against its pinned SHA before and after processing. Every mesh is read with the saved component and build transforms. Source meshes are not repaired, simplified or regenerated.
- Disconnected meshes are sectioned separately, avoiding even/odd cancellation between overlapping parts. Each section's connected components can create new demands, including later petals on one mesh.
- Root propagation reuses the V2 connected-section CAD proxy. Floating sections do not seed future sections. Within-layer extrusion order, native line width and printer raft height remain unknown; lateral CAD continuity is **not native chronology proof**.
- Contact candidates use the existing direct construction with a vertical underside proxy. Full demand raster coverage is required; a single touched point is not sufficient. True surface normals and sub-grid clearances are unverified. No new loft or enlarged receiver is adopted.
- The bounded candidate examines at most 200 eligible demands and adds at most 24 contact routes. It tries the existing direct rule, then the existing rising external branch rule using up to eight nearby frozen plate-rooted shafts. Donor mesh array identities, exact donor intersection and preceding CAD occupancy are checked. All other events and rejection reasons remain recorded. Earlier-BODY surface contact fallback is not connected and cannot be silently counted as solved.
- The finite search is distributed round-robin across 5 mm height bands. It does not spend every attempt near the floor. Detection itself remains exhaustive over the supplied CAD sections; untried events remain listed. Geometry dimensions and acceptance thresholds are not relaxed to obtain a candidate.
- A completed run emits `BEFORE_CACHE_BINDING.json`. `--reuse-before COMPLETED_RUN` reuses its detection only when the source-cache manifest, detection function identity, NumPy version and evidence-file hashes match. Changing precise/light source invalidates it.
- Existing plate-rooted shaft metadata and formal C brace endpoints provide target-side gap audits. Added braces use the original nearest-neighbour, rising-capsule dimensions. These are CAD screening candidates; exact endpoint ownership, lateral vibration, physical buckling and removal remain unverified.
- Counts are **component-sections**, not distinct failed flowers. Aggregated lightweight mesh components are not automatically equivalent to authored flower IDs.
- The recipe is an uncalibrated comparison candidate. `print_go=false` applies only to the new candidate; the Author's current lightweight print continues independently.

## Local uncertainty review (2026-10-23, global HOLD)

`section_reader` v4 retains small nonzero segments using exact rational
intersections of the saved binary-float mesh. Exact grid-centre parity must
agree with the floating scanline/GEOS result; no tolerance increase or mesh
repair. Old v3 cache identities are not silently upgraded.

`local_certificate.Domain` exposes KNOWN_MATERIAL / PROVEN_EMPTY / UNKNOWN.
These are sampled grid-centre states, not solid voxel classifications. UNKNOWN
overrides known material. Continuous query rectangles include between-centre
uncertainty and an explicit halo. Target previous/current/four successor
sections, plate-rooted donor, entire route and clearance are required scopes.
An uncertainty-free query does NOT authorize generation: exact geometric
contacts/collisions and unsampled geometry remain separate gates.

Read-only audit of a sealed v3 cache:

```sh
python -m tools.authored_support.minil.lowz.local_audit --cache SEALED_V3_CACHE --out NEW_AUDIT_DIRECTORY
```

This audits all input seals and original execution snapshots, then screens
known component-section windows against conservative full-component UNKNOWN
envelopes. Counts are windows, not unique flowers or unsupported events. The
existing generator's global UNKNOWN rejection remains in force while full
local certificate integration and the later COPLANAR_FACE replay blocker are
unresolved. No real MINIL candidate is certified by this command.
