MINI_A 自動改善プログラム（0〜100％）

GUI_START.lnk：操作画面を開きます。スタート／ストップ、実行状態、進捗、時間、最新結果、各回の保存ファイルをまとめて確認できます。
表示は2秒ごとに更新します。GUIを閉じても計算は続きます。計算を止めるには「ストップして保存」を押してください。
新しい実行から開始・終了時刻を記録します。以前の実行の計算時間は未記録です。
保存一覧の検証済み行をダブルクリックすると、その回の結果を開きます。未検証の結果と最新の検証済み結果は区別して表示します。
各回の.blendとレポートは保持します。新しい実行の時刻とログはexecution_historyにも保存します。

START_OR_RESUME.lnk：バックグラウンドで探索。前回の続きから再開します。
STOP_AND_SAVE.lnk：現在の候補評価が終わったところで停止し、採用済みの結果を保存・検証します。
OPEN_LATEST.lnk：保存後の再読み込み検証に合格した最新結果をBlenderで開きます。
STARTでは操作用のBlender画面を開きません。AIサービスやネット接続は使いません。

何をするか
1. 支持点からの距離と合流による従来の色評価をそのまま読み込みます。
2. 赤い区間や奥からの支持が不足する花から、近くの枝へ接続候補を作ります。2系統未満の花を優先し、可能なら3系統目も探します。
3. 外形の内側、花から奥へ向かう方向、短い接続という条件で候補を絞ります。
4. 候補を1つ仮に追加し、全モデルの赤い区間の総延長を再計算します。
5. 赤が0.25mm以上減る候補を採用します。赤が増えず、花の奥からの支持系統が増える候補も採用します。
6. 採用するたびに候補順位を計算し直します。不採用候補も次の周回で再評価します。

固定する条件
・対象は0〜100％。色の基準、元の支持点は変更しません。
・点や分岐をまたいで一直線に続く部材も、全体で50mm以下。
・既存の点・枝・削除記録・花の接続を保持。新しい行き止まりを作りません。
・内部同士の追加線は8mm以内、花から奥への線は9.5mm以内。
・花同士や表面をなぞる接続は作りません。花側から4mm以上奥、表面から5mm以上内部の枝へ向けます。
・追加線全体と表示半径0.14mmが元の閉じた外形の内側にあることを確認します。
・点の追加だけを改善と数えません。追加する線も含めた赤の総延長で採否を決めます。

実行と保存
1回あたり、幾何条件を満たす120候補まで色を再評価し、別名の RUN_001、RUN_002…に保存します。
1回で止まっても、START_OR_RESUMEで続行できます。途中の採用結果もcheckpoint.jsonに保存します。
元ファイルと以前の結果は上書きしません。操作中の未保存編集は読み込まれません。
同じ探索を二重起動しないためのロックがあります。
PROGRESS.txt：日本語の進捗。status.json：詳しい進捗、停止理由。run.log / verify.log：詳細。
latest_verified.json：最新の検証済み結果と改善量。
RUN_XXX.json：採用した接続、採用前後の赤の量、検証結果。

停止理由
RED_ZERO：赤がゼロ。
RUN_BUDGET：今回の候補数に到達。再実行で続きます。
USER_STOP：停止ボタンによる保存終了。
NO_IMPROVING_CANDIDATE_IN_THIS_NEIGHBORHOOD：この候補範囲で改善がなくなった。
LINK_LIMIT / ROUND_LIMIT：追加本数または周回の上限。
FAILED：検証または処理が失敗。OPEN_LATESTは前の検証済み結果を維持します。

この版の探索範囲
花の支持数は、花から20mm以内の経路で表面から5mm以上奥へ到達する系統を数えます。花以外の途中点を共有する経路、同じ奥の枝の別々の点に到達する経路は独立した2系統として数えません。表面だけを回る経路や隣の花を経由する経路も除きます。奥へ到達した後の構造全体の独立性・強度を保証する数ではありません。
元の形を保つため「既存の点同士への接続追加」で探索します。枝の削除・付け替え、自由な新規点の配置は探索しません。
局所探索なので「改善候補なし」は数学的な最適解の証明ではありません。
また、現在の評価は支持点までの距離を含むため、内部の一部は接続追加だけでは赤ゼロにできません。
赤の改善はこの評価式上の改善です。印刷用部材の太さや実体の強度計算はこのプログラムの対象外です。

settings.jsonで条件を確認できます。入力や幾何条件を変える場合は、このフォルダを別名コピーしてcheckpoint.jsonを除いた新しい探索として開始してください。
