# Blender操作ガイド

対象：Windows / Blender 5.2.2 LTS、今回のMINI_A専用runtimeで開いたファイル。標準Blender全体のキーマップを説明するものではありません。

## 編集の流れ

1. 検証済みファイルを対応bootstrap付きで開き、`AUTHOR_EDIT_ALL • protected point baseline` を編集します。
2. クリップで対象範囲を絞り、点を選択します。選択点は大きなマーカーで確認します。
3. 2点を選び **F** で仮の枝を接続します。この段階では自動で途中点を増やしません。
4. **Ctrl + Shift + R** または「色を更新」で本線へ反映し、原寸10 mm以上の空き区間に途中点を作り、色を再評価します。
5. 状態がCURRENTになったことを確認して保存します。HOLDの場合は表示された理由を確認します。

| 操作 | 方法・注意 |
|---|---|
| 元の枝／追加した枝の途中に点を置く | **Ctrl + Shift + Alt + A** → 線上をクリック。以前のCtrl+Shift+Aは競合のため変更済み |
| 仮の線をつなぐ | 2点を選択して **F**。3点以上から面を作る用途ではない |
| 色・本線・自動途中点を更新 | **Ctrl + Shift + R** / 「色を更新」 |
| 点から点の区間を複数削除 | 「区間を複数選択して削除」→クリックで選択／解除→ **Enter / X** で削除、**Esc** で終了 |
| 1画面／4画面 | パネルの切替ボタン。保存したビューとクリップを扱う専用機能を使用 |
| 上・前・横・アクソメ | 4画面。正投影3面は専用パン制御で方向を保持 |

外周近傍という曖昧な距離判定ではなく、**花に直接つながる枝を区間削除から保護**します。内部の元の枝も削除対象にできます。保護された花接続を変更したLOWER50/70の生成処理は、削除記録と検証済みの置換経路を組み合わせた別処理です。通常の削除操作による保護解除ではありません。

## クリップ

- 上はZ、前はY、横はXの範囲を0〜100%で指定します。これは対象モデルの軸範囲に対する割合で、mmではありません。
- 数値入力後に「表示範囲を反映」を押します。値変更中に重い再構築を連続実行しない設計です。
- 「全ビュー共通」をONにし軸を選ぶと、例えばZ=0〜15%という同じ切り出しを他のビューでも確認できます。
- 「クリップ面を傾ける」で切り出し方向を傾けます。形状そのものを回転・切断する操作ではありません。
- 範囲反映時は選択を解除します。専用の点追加・選択処理はクリップ外を拾わないように扱います。
- 灰色の領域や標準Blender操作を含めた全表示の完全な同一動作は保証しません。操作が変なら保存済みの正常版をbootstrap経由で開き直し、状態を確認してください。

## 色と奥行き

赤・黄・緑は支持点からのグラフ距離と合流に基づく暫定評価です。新しい線も色更新の対象です。**赤=実物が必ず壊れる、緑=安全保証ではありません。**

単画面の以前の版では手前を明るく、奥を暗くする奥行き表示を作りました。現在のquad由来bootstrapでは、面ごとに異なる方向の濃淡を誤って共用しないため、奥行き濃淡をOFFにしています。単画面に切り替えただけで以前の奥行き表示が再びONになるとは限りません。

## 状態と復旧

- `CURRENT`：その時点の形状から着色済み。
- `STALE`：点・線の編集後。色を更新する必要があります。
- `HOLD`：面の混入、保護点の移動、出所が追えない点・辺、参照の変更など。メッセージに従い編集を戻して再確認します。
- 10 mm分割は同じ空き区間を繰り返し細分化するための操作ではありません。点の追加だけを構造改善と数えません。
- 保存済みファイルだけがoptimizerの入力です。Blender内の未保存編集は計算へ渡りません。
- 作業前のファイル、手編集した基準ファイル、各RUNを残して比較します。以前の結果を新しい結果で上書きしない運用です。
