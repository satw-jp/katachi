# MINI_A レイヤー別保持ルート V2 ガイド

## 起動

`MINIA_ROUTE_EDITOR_START.lnk` を開くと、配布済みV2ファイルへローカル解析パネルを登録します。`.blend` を直接開いた場合は保存済みの静的表示だけになり、動的な保持routeパネルは登録されません。V2 blendと同じ `outputs` にある `route_runtime` は削除・移動しないでください。Blenderの自動実行信頼設定やコマンド入力は不要です。

## 高さ・評価

Nパネルの「MINI_A 保持ルート」で、対象は初期状態ではF3457 DEMOです。損傷位置が判明したという意味ではありません。高さは「モデル高さ（plate Z, mm）」で、0.2 mm格子の幾何学的なplate Zです。過去資料にあるmachine/G-code Zの+0.6 mm換算は未確認で、この高さに加えていません。

「印刷途中・Support込み」と「Support除去後・Permanentのみ」を選べます。高さ、mode、仮想故障対象、Author枝を変えるとSTALEになります。灰色の古い数値やoverlayを現在結果として扱わず、「再評価」を押してください。これは全体graphを指定高さで評価します。Support除去後のgraph数0などは入力graph内の値で、実物の保持経路が0という断定ではありません。

「高さ区間を比較」は、安定した単一のF3457片となる43.0 mm以降について、接続が単調に増えるという仮定の下で成立高さを探索します。全781高さを総当たりした結果ではありません。スライダー操作や自動更新では動きません。処理に時間がかかるため必要時だけ実行してください。今回の編集前後スキャンはbackendのelapsed_s合計19.49秒でした。全検証processは92.23秒でしたが高さ区間以外の評価・保存も含むため、区間ボタン単独の壁時計時間は未分離です。表示するonsetと一本依存区間は、条件付きの宣言graph推定です。接触履歴、toolpath時刻、強度の実測値ではありません。最後の確認実行では編集前区間44.6–156.0 mm、テスト枝後43.2–156.0 mm、二本目は156 mmまで未検出でした。

## 表示の読み方

紫0・赤1・黄2・青3+・灰未確認の凡例があります。青は安全を意味しません。現在の全体graphはMIXEDかつ未確認が残るため、確定色に見立てないでください。青い全長線は編集用source参照で、選択高さまでの保持routeではありません。overlayの灰破線はgraph witnessの模式図です。実表面経路や完全な接触証明ではありません。分離片bboxは個別部材の範囲表示で、実表面形状ではありません。高さより上の追加枝は表示面で切り、橙色で設計意図として示します。

故障対象はbranchまたはjointから選択できます。選択IDが現在高さのgraphにない場合は「対象高さでは未出現／影響は未評価」と表示されます。影響branch数は部分離断を含む関連ID数です。部材破断確率や物理破断予測ではありません。基部まで接続したbranch/flower ID数は、宣言terminalを含む供給graph内のunique ID数です。

## Author枝の追加

初期状態で選択されている編集用アンカーを使います。まず操作練習としてP1/P2付近を確認できます。これは補強の推奨位置ではありません。

1. 編集用アンカーを選択し、`Tab` で編集モードへ入ります。点選択にし、`Alt+A` で選択を解除します。
2. 一つ目の点をクリックし、`Shift` を押しながら二つ目をクリックして、`F` で一本つなぎます。既存点を動かしたり削除したりしません。
3. `Tab` でオブジェクトモードへ戻り、Nパネルの「MINI_A 保持ルート」から「再評価」を押します。編集前／後と残る共通枝を比較します。
4. 必要な場合だけ「高さ区間を比較」を押します。第二経路が増えたか、一本依存区間が変わったかを確認します。
5. 「ファイル → 名前を付けて保存」で、例えば `MINIA_INTERNAL_REPAIR_EDIT_001.blend` として保存します。配布元V1/V2へ上書きしません。

アンカーが選択されていなければ、Outlinerの `AUTHOR_EDIT • DEMO local anchors • select 2 then F` 内の編集用オブジェクトを選びます。全体を編集する場合の参照表示・アンカー切替は `AUTHOR_EDIT_GUIDE.md` を参照してください。

Author用の別meshにedgeを追加する操作です。原本source meshは編集しません。TEST_ONLYの例示枝は配布用V2に含まれず、初期edge数は0です。高さやmodeを変えた場合と同じくSTALEになった後、再評価してください。参照の位置・形状・存在を変えるとHOLDになります。復旧はUndoまたは未変更コピーから行ってください。

編集を保存する場合は別名保存し、返却時にはその `.blend` とこのガイドを一緒に渡してください。次回は起動ショートカットを開いてパネルを登録してから、「ファイル → 開く」で保存した編集版を開き、「再評価」を押します。ショートカット自体は配布元V2を開くため、この手順で編集版へ切り替えます。

## 未確認事項

全実接触の網羅、実toolpath/G-code時刻、raft/bed接続、物理保持強度、花全体の実形状・損傷位置、画面上でのAuthor操作受入は未確認です。表示だけで製造geometryや物理強度をPASSにしません。編集版の差分受入れ後に、追加枝の実材化・局所geometry確認・別途許可されたslice/packageへ進みます。


通常の初回再評価は配布版のfresh起動検査で約9.5秒、編集検知の一回のpollは約0.18秒でした。検知は最大約0.75秒間隔です。PC負荷により変動します。
