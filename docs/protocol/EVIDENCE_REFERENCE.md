# Evidence Reference

Use explicit status vocabulary:

- `PROVEN` — directly verified by the stated evidence;
- `SUPPORTED` — supported by reviewed evidence but not independently rerun;
- `UNVERIFIED` — not established;
- `NOT STARTED` — no execution/evaluation yet;
- `HOLD` — intentionally paused by scope or owner decision;
- `BLOCKED` — cannot proceed without an external change or decision;
- `SUPERSEDED` — retained history no longer represents the current authority.

Keep code, geometry, export, physical, and artistic gates separate. `tests PASS` does not mean `physical PASS` or `artwork PASS`. A branch existing does not prove its capability is present. CURRENT should state proven and not-yet-proven boundaries and point to detailed evidence.
