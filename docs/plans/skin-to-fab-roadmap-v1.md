# SKIN → Permanent Artwork → Removable Support → FAB Roadmap v1

Date: 2026-09-05

This document supersedes `skin-to-fab-roadmap-v0.md` for the current production
direction while preserving v0 as the record of the earlier Permanent Internal
Web-first sequence.

The key update is that the active Usagi candidate must first prove its Reference
Host + Motif Aggregate visually. New Permanent Web/Internal structure is **not**
to be invented in advance. Astra is consulted after the Host OFF Author Gate,
and SKIN then translates/diagnoses the accepted Permanent Artwork before adding
residual Removable Support.

---

## 1. Current layer model

```text
Reference Host
= shape intent / query reference
= may be invisible and printable=false

Permanent Artwork
= Motifs + accepted Permanent Connections / Web / Internal
= remains in finished object

Removable Support
= temporary SKIN fabrication layer
= removed after printing

FAB
= later controlled material-deposition variation
```

These layers must remain distinguishable in data, diagnostics and author-facing
meaning.

---

---

## 3. Reference Host is downstream-invisible but still queryable

For the Usagi candidate:

- the original rabbit STL is not automatically final BODY
- Host OFF means the solid reference is hidden/excluded from printable BODY
- Host query capability may remain active for placement, containment,
  diagnosis and support reasoning
- current author reference instance scale is `20.0x`
- source identity and instance transform remain separate

A Reference Host problem is not a support problem. Invalid/open volume data must
fail closed rather than be guessed around by fabrication logic.

---

## 4. Permanent Artwork decision comes before Removable Support

Astra is asked to study the selected Motif Aggregate as artwork, not as a slicer
problem.

Permanent-artwork questions include:

- which floating Motifs must connect
- where mutual support should emerge
- how early isolated regions enter a stable permanent network
- how to preserve silhouette and bodily character
- how to preserve holes and interior sightlines
- whether any Permanent Internal member is genuinely necessary

If the object remains disconnected or structurally incoherent as an artwork,
return upstream to Astra/author decision.

Only after the Permanent Artwork is accepted does SKIN diagnose temporary
fabrication needs.

---

## 5. Physical evidence retained from Print #1 / #2

Current structural evidence suggests:

- upper connected permanent/internal networks can survive better than expected
- lower isolated regions are more vulnerable
- long thin independent removable supports can wave/collapse
- short near-horizontal permanent members can be viable if they quickly join a
  stable network
- first stable junction / mutual support is more informative than angle alone

Therefore Permanent Artwork evaluation should emphasize:

- unsupported span length
- distance to first stable junction
- branching / mutual support
- neighbor support
- junction spacing
- network-entry timing

Do not invalidate permanent members by angle alone.

For temporary support, Shared Trunk / Branched Tree and low bootstrap bracing
remain useful fabrication directions, but they are not templates to copy into
Astra's Permanent Artwork.

---

## 6. SKIN diagnostics after Astra translation

Once an accepted Permanent Artwork is represented in SKIN, run diagnostics on
that exact structure.

Questions include:

- is the Permanent Artwork one coherent object?
- are Motif-to-Motif connections printable at chosen physical scale?
- are spans unsupported for too long before stable junctions?
- are there collisions or accidental crossings?
- are permanent members visually excessive?
- do openings/sightlines remain as intended?
- what residual temporary assistance is actually needed?

Do not let Removable Support silently alter the accepted artwork geometry.

---

## 7. Removable Support remains residual fabrication aid

Preferred direction:

```text
Accepted Permanent Artwork
↓
physical diagnostics
↓
remaining fabrication-only unsupported regions
↓
few stable roots/trunks
↓
early enter stable support network
↓
shared lower corridors where viable
↓
branch / local approach / distributed contacts
```

Temporary support may use Shared Trunk / Branched Tree or other proven
fabrication approaches, but it must remain removable and semantically separate
from Permanent Artwork.

---

## 8. Conventional print baseline before FAB

FAB remains later.

The ordinary print must first be sufficiently repeatable that material-process
variation can be distinguished from basic failure.

```text
same accepted Permanent Artwork
+ same orientation / scale
+ stable slicer profile
+ stable material profile
= conventional baseline
```

Only then should FAB deliberately vary deposition.

---

## 9. FAB role

FAB controls how material is laid down, not whether the artwork is structurally
coherent.

Potential later channels remain:

- feed
- extrusion amount / flow
- dwell / pacing
- bounded sag
- local thickness fluctuation
- other deterministic material-process variations

FAB variation must be disableable so the conventional baseline remains
reproducible.

Do not use random process noise as a substitute for authored irregularity.

---

## 10. Astra artifact → SKIN compatibility

Astra should ideally retain a semantic artwork artifact rather than only a
flattened STL or current FKEI.

```text
Astra Artwork Artifact
↓ SKIN adapter
SKIN-compatible FKEI / project state
↓
SKIN diagnostics / Removable Support
```

If current SKIN cannot represent some Astra semantics, the adapter should report
loss/unsupported data explicitly.

Astra's permanent-artwork canonical representation should not be limited merely
to satisfy current FKEI.


---

## 12. Guardrails

Do not confuse:

```text
Reference Host
Permanent Artwork
Removable Support
ordinary slicer profile
FAB expressive variation
```

Additional rules:

- do not make the rabbit solid final BODY by default
- do not auto-repair original STL source
- do not invent Permanent Internal/Web before the Host OFF author gate
- do not ask Astra to solve temporary printer support
- do not use Removable Support to hide disconnected Permanent Artwork
- do not use FAB to repair artwork geometry
- do not make FKEI Astra's canonical ceiling

---

## Guiding production principle

```text
First establish the body as a Reference Host.
Then let Motifs carry that body's presence.
Then decide the permanent artwork structure.
Then add only temporary fabrication aid.
Then make ordinary printing repeatable.
Only then deliberately vary material deposition.
```
