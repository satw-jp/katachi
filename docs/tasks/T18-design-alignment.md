## Part A — 意匠の正: satw.jp のデザイントークン（全リポジトリ共通）

2026-07-17 に本番（https://satw.a-8c3.workers.dev/）の実測から採取した。
**サイトが正、道具が従う。** 各リポジトリはこのブロックをそのまま持つ
（クロスリポジトリの共有パッケージは作らない — 大げさすぎる。変更時は手で同期し、
このファイルを正とする）:

```css
:root {
  --paper: #fbfbf9;                      /* 地。ページとパネルの背景 */
  --ink: #1c1c1a;                        /* 図。本文・ラベル・実線 */
  --mist: #8e8c84;                       /* 二次テキスト・キャプション */
  --faint: #c9c7bf;                      /* 無効状態・三次 */
  --hairline: rgba(28, 28, 26, 0.12);    /* 罫線。境界はすべてこの細線 */
}
/* 書体と組み */
font-family: "Helvetica Neue", Helvetica, Arial, "Hiragino Kaku Gothic ProN",
             "Hiragino Sans", "Yu Gothic", Meiryo, sans-serif;
font-size: 14px; line-height: 1.8;      /* 本文 */
/* ナビ・ラベル: 15px / letter-spacing 0.06em / weight 400 */
```

### 意匠の原則（トークンより重要）

1. **紙と墨とヘアライン。** 面は --paper、文字は --ink、境界は --hairline の1px。
   影・ぼかし（backdrop-filter）・グラデーション・大きな角丸は使わない
   （角丸は 0〜2px まで）
2. **色はアクセントに使わない。** サイトに青リンクは無い。強調は太さではなく
   字間と余白で行う。weight は 400 基調、見出しでも 500 まで
3. **計器の色は意匠ではない。** データを語る色（Katachi の応力スケール
   青(0.30,0.55,0.95)↔赤(0.95,0.25,0.20)＝作者承認済み、Kumo の空や温度の色）は
   **触らない**。今回置き換えるのは UI の chrome（パネル・ボタン・文字・地）だけ
4. **静かな操作部。** ボタン = paper 地 + hairline 罫 + ink 文字。hover は罫を
   ink に近づける程度。danger も彩度を抑える（例 #7a2e2e 系。原色の赤は使わない）

## Part B — Katachi（このリポジトリ）

**依存: [T16](T16-consolidation.md) の T16-3（style 共通化）を先に終えること。**
現在 style.css が8枚（計約2,100行）に分岐しており、先に共通部を
`src/styles/base.css` へ抽出（見た目不変）してから、この T18 で base.css を
一箇所書き換える。T16-3 未了のまま8枚を個別に塗り替えることを禁ずる
（同じ変更を8回して9枚目の分岐を作るのがこのプロジェクトの病歴 — T16 冒頭）。

- 現状: ダークテーマ（--bg #101114 / --text #e6e6e9 / アクセント青 #6fb1ff・
  color-scheme: dark）。これを Part A のトークンへ置換
- アクセント青 #6fb1ff を使っている UI 部品（リンク・選択状態・スライダー等）は
  ink 系へ。**ただし 3D ビューポート内の選択ハイライトや計器の色は「計器」側 —
  変更しない**（原則3）
- フォントを Part A のスタックへ（-apple-system をやめる）
- Version / UpdatedAt 行・デバッグ折りたたみの様式は維持（表示形式は変えず色だけ従う）

### 地の色 — 裁定済み（作者 2026-07-17）

**「地の色はとりあえずそのままでいい」= 3D ビューポートの背景（#101114 系）は
現状のまま残す。** パネル・文字・操作部だけを紙白の chrome にし、ビューポートは
「窓」として暗地を保つ。切り替え機構は作らない（決定済みのため）。
将来変えたくなったら作者の一言で1定数の変更。

## Part C — Kumo（active/Kumo リポジトリ）

- 現状: セージグリーンの世界（地 #cbd7ce・深緑の文字・すりガラスパネル
  rgba(247,248,244,0.9)+blur・角丸6px・影）。style.css は1枚（約270行）なので
  直接置換でよい
- パネル・ボタン・見出し・questions パネルの chrome を Part A へ:
  すりガラス → 不透明の --paper + hairline、影と blur を落とす、角丸 0〜2px、
  フォントを Part A のスタックへ（Inter をやめる）
- **3D シーンの中身（空・雲・地表・温度凡例の色）は触らない**（原則3）。
  is-sky モードの白文字+シャドウは可読性の機能なので維持してよい
  （シャドウ禁止の例外として明記）
- **地の色 — 裁定済み（作者 2026-07-17・Part B と同じ）**: シーンの地
  （#cbd7ce と .top-view-canvas 等のシーン内背景）は現状のまま残す。
  紙白に置き換えるのはパネル・questions・見出し等の chrome だけ

## 進め方（両リポジトリ共通）

1. トークンと原則を base.css / style.css の先頭に移植（コメントで
  「正 = Katachi docs/tasks/T18-design-alignment.md Part A」と一行）
2. chrome を置換。**1ページ（Study）ずつ**、before/after のスクリーンショットを残す
3. 全ページの before/after を作者に提出し、視覚確認を受ける
4. 承認後にデプロイ（T17 Part D の型: deploy → 公開URLで確認）
5. 各 Study の manifest revisits に一行（「UI chrome を satw.jp トークンへ統一」）

## スコープ外

- サイト（satw.jp）側の変更 — サイトが正であり、動かすのは道具側だけ
- レイアウトの再設計（パネルの位置・幅・情報の並びは現状のまま。変えるのは色・
  書体・罫・影のみ）
- 計器・データの色（原則3）
- Katachi のホーム/ナビ再設計（T16 判断ポイント1のまま別件）
