# T2b — たわむ（Study: S2b・柔らかさ）

対象: 実装モデル（モデル非依存）。着手前に STATEMENT → RESEARCH → AGENTS → この文書を読む。
共通規約は [README.md](README.md)。土台は S1（形の場・履歴）と S2（地面・苦しさの近似・色）。

## 目的

**材料の場の初登場。** 柔らかさのつまみを動かすと、雲が力に**形で応答する** —
柔らかい雲は自重で潰れて裾が広がり、硬い雲は形を保つ。それだけ。
S2 は力を色で報告した。S2b は力を形で見せる。

作者の言葉（2026-07-09、この Study の発注そのもの）:
「今は素材が未知だから柔軟さみたいなパラメータを動かしたときにどのように変形するかとかが見てみたい」

**作者裁定は T2 と同じ: 粗く・早く。** バネの素描でよい。弾性論ではないことを画面に正直に書く。

## 一番大事な設計の線（省略不可）

**こねた形（休んでいる形）が正本。たわみは導出物。**
- 履歴に乗るのは: こねる操作（S1 と同じ）＋つまみの変更（柔らかさを含む）
- 履歴に乗らないのは: たわんだ後の球の位置（毎回、正本＋柔らかさから純関数で再計算する）
- export→import で、同じ休み形・同じ柔らかさ・**同じたわみ**が再現されること

これは命題の構図の実装でもある: 休んでいる形（見かけ）と、力の下で本当に起きている形（実際）の
**差**を、初めて形の差として見られる。

## 作るもの

`src/studies/sag/` に自己完結の Study 一式。S1 の `field.ts`/`picking.ts`、S2 の `physics.ts`

入り口は `sag.html`（マルチページ vite に追加）＋各 Study パネルからの素朴なリンク。

### 1. 柔らかさのつまみ

- スライダー一本: **柔らかさ** 0（剛 — たわみゼロ、S2 と同じ見た目）〜 1（柔 — 大きくたわむ）
- 材料は当面**一様**（全球同じ柔らかさ）。球ごとの材料は後の段
- 柔らかさは材料の場のパラメータ = 作品の定義の一部なので、変更は履歴に記録する（S1 の setParam の流儀）

### 2. たわみの計算（粗い近似）

方向性の例（技術選定は自由 — AGENTS §2。選んだ式と根拠を README に残す）:

- S2 と同じ球グラフ（重なり=接続）をバネと見なす。バネの硬さ ∝ (1−柔らかさ) × 接続断面積
- 各球に自重（体積比例）が下向きにかかる。地面は貫入禁止（y ≥ r の拘束）
- 反復緩和（Jacobi/Verlet 的なもの）で釣り合いまで解く。毎フレームでなくてよい —
  正本か柔らかさが変わったときに再計算すれば十分
- 発散したら（バネが伸び切る等）その球を最大の苦しさ色にして「壊れた」と正直に言う。
  アニメーションは不要（釣り合いだけ見せる）。ただし応答性は大事 —
  スライダーを動かしてから絵が変わるまでの実測を README に残す（AGENTS §5）

### 3. 二枚の姿

- **たわんだ形**を本体として表示（S2 の苦しさ色をたわみ後の配置で再計算して着色）
- **休んでいる形**を薄い残像（ゴースト）として重ねて表示できること（トグルで on/off）。
  差が見えることがこの Study の眼目 — たわみ量が大きいほど二枚がズレる
- こねる操作（クリック・ドラッグ・個別半径）は**正本（休み形）への編集**。
  ピッキングはたわんだ表示に対して行い、当たった球の休み形を編集する（同じ id の球）

### 4. 色と正直さ

- 色は確定済みパレット（青 rgb(0.30,0.55,0.95) ↔ 赤 rgb(0.95,0.25,0.20)、作者承認 2026-07-09）を
  **そのまま使う**。新しい色を発明しない
- 常設バナー: 「粗い近似: バネの素描。弾性論ではない。実物の保証はしない。（S3 で実物と校正予定）」

### 5. Study の体裁

- `README.md`（Question/Setup/Observation/Hypothesis/Related/Next）。Question は例えば
  「柔らかさ一本のつまみで、たわみの手応えはどこまで本物に近づくか」— 起草してよいが作者の言葉を上書きしない
- `manifest.json`・画面に Version/UpdatedAt・デバッグハンドル `window.__sag`（S1/S2 の型に倣う）

## やらないこと

- 風・空気の流れ（T2c — この Study の結果を見てから起草する）
- 本物の弾性 FEM・座屈・破断・アニメーション物理（時間発展を見せる必要はない、釣り合いだけ）
- 球ごとの材料の違い・ケブラー等の異方性（後の段）
- 印刷用出力（T3）

## 完了条件

1. 柔らかさ 0 でたわみゼロ（S2 と同じ配置）、1 に向けて連続的に潰れていく
2. 柔らかい雲が地面の上で**裾が広がる**（潰れが縦だけでなく横に逃げる）様が見える
3. ゴースト表示を on にすると休み形とたわみ形の**差**が見える
4. こねる操作がたわみ表示の上から自然にできる（クリックで追加・選択、個別半径も効く）
5. export→import で同じ休み形・同じ柔らかさ・同じたわみが再現される（たわみ位置は履歴に無いこと）
6. 近似の説明が画面に常設、選んだ式・剛性の定数・応答速度の実測が README に理由つきで記録
