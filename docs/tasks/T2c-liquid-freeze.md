AGENTS → この文書を読む。共通規約は [README.md](README.md)。

## 目的（Y5 相の造形・作者の言葉が発注）

「柔らかさを1にしたときに**地面にベタッとなるような液体っぽいもの**になると良い」
「気体と液体の特性のような形状を**固体として出力**できたら面白そう」

今の柔らかさ1は「潰れた固体」止まり。これを本物の液体の端にする — 球が滑って濡れ広がり、
池になる。そして「**凍らせる**」— たわんだ一瞬を正本に焼き付け、形を手に取り戻す操作を作る。
これが「このソフトでしか出来ないかたち = 力の履歴の凍結」の最初の実装。

**作者裁定は一貫: 粗く・早く・正直に。** 流体力学ではない。表面張力の素描でよい。

## 作るもの

### 1. 液体の端（柔らかさ 1 付近の挙動を差し替える）

方向性の例（技術選定は自由 — AGENTS §2。選んだ式と根拠を README に残す）:

- **液体は接続の記憶を持たない**: 固体側は今の永続バネ（休み形の接続を保つ）でよいが、
  液体側は緩和の反復中に**接続を毎回組み直す**（今の近接だけで決める）。柔らかさで両者を混ぜる
- **濡れ広がり**: 重力＋地面貫入禁止＋近接球の凝集（表面張力の素描 — 近い球は引き合い、
  重なりすぎは押し返す）で、球が滑り落ちて横に広がり、一〜二球厚の池に落ち着く
- 球は球のまま（楕円化・分裂・合体はしない）。池らしさはメタボールの smooth-min が作る
- 落ち着いた池は**ほぼ青一色**になるはず（液体は基底状態に流れ落ちた形 — H1 の物理版。
  池が赤かったら何かおかしい、という検算に使える。点接触の特異点だけは例外、記録すればよい）

### 2. 凍らせる（新しい履歴 op `freeze`）

- パネルにボタン「**凍らせる (Freeze)**」。押すと:
  1. 現在の**たわみ形を正本（休み形）に焼き付ける**（導出物が正本に昇格する、初めての手）
  2. 柔らかさを 0 に戻す（固体 = どの力にももう従わない、が Y5 の相の定義）
- 履歴には `freeze`（引数なし）1件で記録する。replay 決定性が必須:
  たわみ計算は（正本・柔らかさ・パラメータ）の純関数で反復数固定なので、
  同じ履歴を再生すれば同じ焼き付け結果になること（snapToGround と同じ設計原理）
- 凍らせた後も**こねる操作は普通に続けられる**（凍ったしぶきに球を足す・削る・また柔らかくして
  もう一度たわませる… が全部履歴に乗る）。相を往復した履歴こそこの道具の作品の形

### 3. 表示と言葉

- つまみのラベルは当面「柔らかさ」のまま（「相」への改名は気体の端 = 風が入る T2d のときに
  作者が決める。UI の押し付けをしない）
- 正直バナーに一言追加: 表面張力は素描である旨（例:「液体は表面張力の素描。流体力学ではない」）
- ゴースト（休み形）は freeze 直後に本体と一致するはず — それが「凍った」ことの視覚的な証拠になる

## やらないこと

- 風・気流（T2d）。メッシュ書き出し・印刷用出力（T3 — ただし freeze はその前提づくり）
- 流体シミュレーション（SPH 等の本物）。球の分裂・合体・楕円化
- S1/S2 の変更。S2b の既存挙動（中間の柔らかさのバネたわみ）の破壊

## 完了条件

1. 柔らかさ 1 ＋接地で、雲が**池になる**: 高さが休み形より大幅に低く・広がりが大幅に大きく、
   一〜二球厚に落ち着く（数値を README に実測記録）
2. 落ち着いた池がほぼ青（基底状態の検算）
3. 中間の柔らかさ（例 0.4）は T2b と同等の「柔らかい固体」のたわみのまま
4. 「凍らせる」でたわみ形が正本に焼き付き、柔らかさが 0 に戻り、ゴーストが本体と一致する。
   その後もこねる操作が正常に続けられる
5. `freeze` を含む履歴の export→import で同じ形が再現される（replay 決定性）
6. T2b の完了条件6項目が引き続き全部通る（回帰確認）。README Observation・manifest 版上げ
   （0.2.0）・revisits 追記・`npm run build` 通過
