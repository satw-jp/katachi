## 作るもの

### 1. 詰める単位の切替: 球 / 雲

- **球**: 現行のまま（無変更）
- **雲**: 単位 = 小さな球の群＋ローカルな丸さ k（S1 の growBalls の流儀で生成 —
  シードから決定的に。単位ごとに違う形になるようシードは単位毎に派生させる）
- 雲単位のつまみ: **単位の球数**（例 3〜10）・**単位内の半径ばらつき**・**単位の丸さ k**
  （単位内のブレンド。合成全体の丸さ k とは別）・既存の大きさ下限/上限は**単位の外接半径**として働く
- 配置はランダム回転つき。衝突判定（clearance）は**単位の外接球**で粗く取る
  （精密判定はしない — 詰め方の偶然が価値。近似であることを README に）

### 2. 自作の雲を単位にする（S1 レシピ = 詰め材）

- 「**単位として S1 レシピを読み込む**」: 読み込んだ雲（球リスト＋k）を単位の原型にし、
  スケール（大きさ下限〜上限に正規化）＋ランダム回転で複製配置する。
  作者が手でこねた雲・凍らせたしぶきが、そのまま詰め材になる
- 原型は複数登録できると望ましい（最低1つでよい。複数なら単位ごとにランダム選択）

### 3. 両モードで機能

- **実体に虚を詰める**: 雲形の空洞 → 残る骨組みが有機的な洞窟状に
- **虚に実を詰める**: 雲の単位が型枠に積もる → 雲の石積み
- ビーズ表示・全体メッシュ・計器（最薄の肉は単位の外接球ベースの近似でよい、正直に注記）・
  飽和処方箋・重ね詰め（乱数の続き）はそのまま生きること

### 4. 履歴

- 詰め op は**結果（各単位の球リストと単位メタ）を引数に持つ**現行の流儀を維持。
  replay で完全再現。単位境界（どの球がどの単位か）も保存（選択・削除が単位ごとに効くため）

## やらないこと

- 単位同士の精密な衝突・充填最適化。単位の変形（置いた後の雲の個別編集は次便）
- skin への展開（pack で立ってから）
- 既存機能の変更

## 完了条件

1. 単位「雲」で詰められ、単位ごとに形が違う（シード派生の確認）。球モードは無退行
2. S1 レシピを単位として読み込み、複製配置できる（読み込んだ形が単位として認識できることを
   ビーズ/メッシュ表示で確認）
3. 両モードで機能: 雲形の空洞の骨組み／雲の石積み、それぞれ STL 水密の実測
4. 重ね詰め・段階詰め・飽和処方箋・表示三段・自動切替が雲単位でも機能
5. 履歴 export→import 完全再現（単位境界含む）
6. 実座標クリック検証・既存8ページ無退行・README（単位生成の式・外接球近似の注記・実測）・
   manifest 版上げ（0.3.0）・`npm run build` 通過
