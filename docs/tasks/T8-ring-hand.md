## 作るもの

`src/studies/rings/` に自己完結の Study 一式（`rings.html`、ナビリンク、Version/UpdatedAt、
README、manifest）。場の定義は S1 と同じ（`field.ts` を import、球のリスト＋smooth-min k）。

### 1. 輪を生む（単位の第一号）

- 「輪を追加」: 中心・向きを持つ円周上に**球の鎖**を並べて一つの輪にする。つまみ:
  輪の半径 R／節の数 n／球の太さ r／ふわつき（半径・位置の揺らぎ、シード付き —
  作者の 3rings は節が不揃いで、その不揃いが生命感を出している。均質な輪はおそらく死ぬ）
- 内部表現は**あくまで球のリスト**＋「この球たちは輪 #k に属する」というグループ情報。
  履歴 op は `addRing`（中心・軸・R・n・r・揺らぎ・シードを引数に持ち、決定的に球へ展開）

### 2. 単位の手（関係を作る操作）

- 輪を**単位として選択**（球クリック→属する輪全体が選ばれる。個別球の編集は S1 に任せ、
  ここでは単位の手に集中）
- 単位のドラッグ移動・回転（軸まわり＋向きの変更。マウスで素朴に。数値入力も）
- 単位の複製（同じ輪をもう一つ、少しずらして生む — 集積の最小手）
- 削除。すべて履歴に記録（`moveRing`/`rotateRing`/`duplicateRing`/`removeRing` 等、
  引数に結果を決定的に再現できる値を持つこと）

### 3. トポロジーの計器（この Study の Yohaku らしさ）

- **絡み数（Gauss linking number）を常時表示**: 輪の中心線（節点を結ぶ閉じた折れ線）の
  ペアごとに絡み数を計算し、「輪1と輪2: 絡み 1」「輪2と輪3: 絡み 0」のように一覧する。
  作者は「新しいトポロジーを作りたい」— なら道具は**いま何のトポロジーができているかを
  正直に言う**べき（計器の思想の、力学から位相への拡張）
- 交差の警告: 輪同士の球が深くめり込んでいる場合はその旨表示（絡みではなく融合になっている）

### 4. 出口（既存資産との接続）

- **S1 レシピ書き出し**（球のリストに展開。グループ情報は失われてよい — 正本の互換性が優先）。
  これで STL 化（S1 の門）・溶かす（MPM）・泡化（foam）が全部利く
- STL 直接書き出しがあればなおよい（S1 の meshExport 共有。無理はしない）

## やらないこと

- 物理・重力・たわみ（置く手だけ。絡んだ輪がぶら下がる、は後の便で MPM に投げれば出る）
- パッキング・格子充填（次便候補。まず輪と関係の手）
- 輪以外の単位（貫通箱・殻セル等は輪の結果を見てから）
- 既存 Study の変更

## 完了条件

1. つまみで輪が生め、ふわつきで 3rings 的な不揃いの節が出る
2. 輪を単位としてドラッグ・回転・複製でき、**別の輪にくぐらせて絡ませられる**
3. 絡み数が正しく表示される（絡めたら 1、外したら 0 — 検証は既知の配置で）
4. S1 レシピ書き出し → S1 で開いて STL 化まで通る（水密）
5. 履歴 export→import で同じ形・同じグループが再現される
6. 実座標クリック検証・既存4+1ページの無退行・README（絡み数の式と出典・応答実測）・
   manifest・`npm run build` 通過
