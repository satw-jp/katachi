## 目的(Y7 が発注)

作者の三つの形の欲望のうち①②を一本のつまみで:
①**穴の空いたセル**が組み合わさって一つの形になる
②**穴が開いて糸みたいな構成要素だけが残り、体積は無いがかたちの存在感は残る**

雲(球のリスト)をセルに分解し、**開口のつまみ一本で 体積 → 穴あき殻 → 糸 まで連続に掃引**する。
糸の正体は泡の Plateau 境界(膜が破れて縁だけ残る)— Y5 の相の系譜(泡=気体と液体の複合相)。
③絡まり合いは次のタスク(軌跡の凍結)。この便ではやらない。

### 1. 場の定義(正本は球のリストのまま — 泡は導出のレンズ)

- 入力は S1 と同じ球のリスト(既定の grow ＋ S1 レシピ読み込み。field.ts を import 共有)
- **セル分解**: 球の中心を種とする分割。素朴には最近傍/2番目最近傍の距離差でセル壁を定義
  (半径を重みに使う power 距離も可 — セルの大きさが球の大きさに追従する。選定と理由を README に)
- **泡の SDF**(方向性の例 — 技術選定は自由、式を README に):
  - 雲の内部(fieldSdf < 0)に限定した Voronoi 壁 + 外殻(|fieldSdf| < 厚み)
  - **開口**: 壁/殻は「セルの縁(3セル等距離線 = Plateau 境界)から遠いところ」から順に消える。
    開口 0 = 閉じた殻のセル群 → 開口を上げる = 各面の中央に穴が開き広がる → 開口 1 付近 = 縁の糸だけ
  - 表示は S1 と同じレイマーチ(球数上限内なら最近傍3中心の逐次探索でシェーダ内計算可。
    重ければ CPU で 3D テクスチャに焼いてサンプル — 応答速度の実測を README に)

### 2. つまみ(履歴に記録 — 作品の定義の一部)

- **開口**(主役。0=閉殻 〜 1=糸だけ)
- **厚み**(殻/糸の太さ。印刷可能性に直結)
- 既存の S1 つまみ(球数・半径・ばらつき・k・シード)も同居(場の元は同じ)
- すべて setParam の流儀で履歴に記録。export→import で同じ形が再現されること

### 3. 出口

- **STL/OBJ 書き出し**: S1 の meshExport(marching tetrahedra)の機構を泡の SDF に差し替えて再利用
  (コピーせず関数を共有できる形が望ましい — SDF を引数に取る形への一般化は可。
  ただし S1 側の挙動を変えないこと)。実寸 mm・水密検査・レシピ対保存も同じ
- 糸の構造は細くなるほど水密メッシュ化が難しい(解像度に対して糸が細すぎると千切れる)。
  **千切れたら千切れたと正直に表示**(水密検査があるので検出できる)。
  「この開口・厚みなら解像度いくつで水密になった」の実測を README に

## 完了条件

1. 開口 0: 穴のない殻のセル群が組み合わさった一つの形(画像①の系)が見える

3. 厚みつまみで殻/糸の太さが変わる
