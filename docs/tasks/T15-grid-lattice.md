## 発注（作者の言葉 2026-07-14 — この言明が仕様の核）

「虚を詰めるは**内部の構造**の作り方、表面を詰めるは文字通り**表層**の作り方。
見た目のまとまり具合で言うと後者のほうが**作品化しやすい**。
後者の考え方と前者の内部の作り方を**混ぜ合わせる**方法って考えられる？
例えば**内部にもコインやリングを詰める**。
いきなり有機的なところから始めると複雑すぎてわからなくなりそうだから
**グリッドパターンとか凄くシンプルなところから**」

設計の翻訳: 表層の語彙（向きを持つ平たい単位）を内部へ。配置は**秩序から始めて揺らぎを足す**
（H1 の実践 — ランダムを単純化するのではなく、格子にばらしを注ぐ方向で作る）。

## 作るもの（S-pack v0.4）

### 1. 単位の追加: コイン / 平リング / 立体リング

- skin の形状生成（buildCoinPoints / buildFlatRingPoints / buildRing3dPoints 相当）を
  pack の単位として移植（共有できるなら共有、コピーなら理由を README に）。
  既存の 球 / 雲 / S1原型 と並ぶ選択肢に
- コイン・平リングは**向きを持つ**: 法線の向きは配置モードから与えられる（§2）

### 2. 配置モード: ランダム（現行・貪欲） / **グリッド（新設）**

- **グリッド**: 立方格子の格子点に単位を置き、ホスト内部の点だけ採用（外接球がホストに
  収まるか、で判定 — 端の単位が表面で切れるかは「食い込み」つまみの流儀に従う）
- グリッドのつまみ:
  - **間隔**（一様。異方はまだ）
  - **千鳥**（層ごとの半ピッチずらし on/off — 煉瓦積み/市松）
  - **向き**: コイン/リングの法線を X/Y/Z から選ぶ。**層ごとに交互**（合板/クロスライク）も
  - **ばらし**（0〜1）: 0 = 完全格子。上げると位置・回転・大きさに揺らぎが注がれ、
    1 で現行のランダム詰めに近い表情へ。**この一本がグリッドと有機の橋**（H1 の物理版 UI）
- 履歴 op は現行の流儀（結果の単位リストを引数に持つ）。グリッドでも決定的（シード×ばらし）

### 3. 両モード・両 Study の資産で機能

- **実体に虚を詰める** × グリッドのリング/コイン: 内部に規則的な空隙構造 —
  リング形の空洞が格子状に並ぶ「構造化された骨」（印刷のインフィルの美学と地続き）
- **虚に実を詰める** × グリッド: リング/コインの格子がホスト形に刈り込まれた作品
  （表層の作品性が内部の秩序として立つ — 作者の「混ぜ合わせ」の直答）
- ビーズ/全体メッシュ/計器/飽和処方箋/重ね詰め（グリッドでは「再詰め=残りの格子点を埋める」）は
  現行のまま生きること。STL 水密の実測（リング格子の細い接続は解像度依存 — 正直に）

## やらないこと

- 異方格子・六方最密・準結晶（グリッドの次の便）。skin 側への逆移植
- 単位の個別編集。物理との統合
- 既存機能（ランダム詰め・球/雲/原型）の変更

## 完了条件

1. 単位コイン/平リング/立体リングが pack で使える（両モード）
2. グリッド配置: 完全格子（ばらし0）で規則正しく並び、間隔・千鳥・向き（層交互含む）が効く
3. **ばらし**が連続に効く: 0=格子 → 1=ランダム詰めに近い表情（中間のスクリーンショット必須）
4. 実体に虚（リング格子）→ 内部空隙構造の STL 水密実測／虚に実（リング格子）→ 刈り込まれた
   格子の STL 水密実測（分離部品数の正直表示）
5. 履歴 export→import 完全再現・v0.3 機能の無退行
6. 実座標クリック検証・既存8ページ無退行・README（格子の式・ばらしの注入先・実測）・
   manifest 版上げ（0.4.0）・`npm run build` 通過
