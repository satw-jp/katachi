## Printability claim boundary

Integrated v1 print proxies are not sufficient proof. In v1, stronger print bias improved some local support proxies but did not eliminate island behavior. Therefore do not call a proposal `print-proven` from proxy metrics alone.

Use three evidence levels and name them precisely:

### Level 1 — generative print-causality

The Permanent Structure generation must explicitly use already-established lower-to-higher printable state / build direction as part of the same growth history.

### Level 2 — manufacturing preflight

For the **Permanent Structure only**, at 1000% and the locked build orientation:

- produce a manufacturing mesh suitable for slicer inspection;
- union / connectivity / manifold / watertight state must be audited;
- run layer / island / overhang / reachability diagnostics;
- inspect in the intended Bambu workflow / profile when available;
- identify whether any slicer-generated support would be required **for the Permanent Structure itself**.

Then repeat the relevant demand / slicer inspection for D1 and D2 so the support hierarchy can be measured.

The target is that Permanent Structure does not depend on inaccessible internal removable / slicer support. Bed-adhesion aids or clearly external temporary aids may be reported separately and must not be conflated with internal structural printability.

### Level 3 — physical proof

`PRINT-PROVEN` for the Permanent Structure requires a real 1000% **Permanent-Structure-only physical print** under a recorded printer / nozzle / material / process profile, with:

- print completion;
- no inaccessible internal support dependency;
- bed removal / handling outcome recorded;
- breakage / weak junctions / sag / severe defects recorded;
- photos or equivalent physical evidence.

A later whole-system physical print may use the D2 authored Support and D3 slicer fallback, but that must be reported separately from the Permanent-Structure-only proof.

If Research Astra cannot perform the physical action, prepare the exact artifact + profile + checklist and STOP at **READY FOR AUTHOR PHYSICAL GATE**. Do not self-certify physical printability.
