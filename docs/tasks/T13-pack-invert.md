## 作るもの

### 1. 地と図の反転（skin の流儀）

- モード切替ボタン2つ（skin と同じ見た目・同じ位置感）:
  - **実体に虚を詰める**（現行）: composite = smooth-subtract(host, voids)
  - **虚に実を詰める**（新設）: ホストは**型枠** — 配置の拘束にだけ使い、印刷されない。
    composite = 詰めた球たちの smooth-union（丸さ k は既存つまみ）。
    ホストは半透明の下敷きとして表示（skin のビーズ表示のホストと同じ扱い）
- 同じパッキング結果に対してワンタッチで行き来できること（skin と同じ体験）
- レシピにモードを記録。STL 書き出しは両モードで水密（反転モードは球集積の union —
  離れた球があれば分離部品。skin と同じく連結成分数を正直に表示）

### 2. 詰めの挙動を skin の改善と揃える（同じバグが眠っている前提で点検）

- **乱数の続き**: pack の貪欲詰めも `hashSeed(params.seed)` で毎回同じ列を再生しているはず。
  skin と同じ修正（`hashSeed(seed + "#" + voids.length)`）で、重ね詰め・段階詰め
  （大→中→小）が機能するように。検証も skin と同じ型で（同一条件3連続パックで2回目が
  +0 でないこと・下限を下げた追い詰めが効くこと）
- **飽和の処方箋**: 飽和時に琥珀色で「下限サイズか隙間を小さくせよ、試行数では破れない」
  （skin の文言に倣う）

### 3. 表示を skin v0.3 と揃える

- **ビーズ表示**（InstancedMesh・容量無制限）: 虚の球も実の球も全量描く。
  現行モードでは虚を区別色（例: 暗色/ワイヤ感）で、反転モードでは実を本体色で。
  総数がレイマーチ容量を超えたら**自動切替**＋その旨表示（黙って先頭だけ描くのを廃止）
- **全体をメッシュで表示**（skin の setMeshOverlay の流儀）: STL と同じ実データの lit mesh。
  状態が変わったら自動でビーズ/レイマーチへ戻す
- 選択ハイライトが容量外で死ぬ問題も skin と同じ構図のはず — ビーズ表示側で選択色が
  常に見えることを確認

## やらないこと

- 虚の形の多様化・pack と skin の統合 UI・他 Study の変更
- レイマーチ容量そのものの拡張

## 完了条件

1. 反転モード: ホストが型枠になり、詰めた実球の集積が作品として表示・STL 化できる（水密実測）。
   ワンタッチで現行モードと行き来できる
2. 同一条件の重ね詰めが効く（3連続パックで2回目が +0 でない）・段階詰めが効く・飽和の処方箋が出る
3. ビーズ表示で全量が見え、容量超過で自動切替（通知つき）。メッシュ表示も動く
4. 選択がビーズ表示で常に見える
5. 履歴 export→import 完全再現（モード含む）・既存モードの無退行
6. 実座標クリック検証・既存8ページ無退行・README（反転の式・実測）・manifest 版上げ・
   `npm run build` 通過
