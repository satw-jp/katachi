## Core problem to fix

The latest package established a strong visual direction but exposed one shared structural failure:

```text
algorithmic ancestry exists
but
material ancestry is incomplete
```

Current evidence includes:

- D0: `54` layer-island births remain, including `41` at Host depth >= 2 mm;
- D0: printable / established growth state remains only `5 / 96` internal nodes;
- D1: exact A2 0.5x / 512 motifs are placed by causal history, but `36` motif groups remain physically disconnected from D0, producing `37` positive solid components including the Permanent body;
- D3: slicer fallback removes the Bambu floating warning, but approximately `41.37%` of actual Support path length lies at Host depth >= 2 mm, so internal removable-Support dependence remains unresolved.

The next hypothesis is:

> If Permanent growth is propagated from an already-printable frontier and is required to close the same material path all the way to surface emergence, then D0 printability and D1 motif connectivity may improve together without sacrificing the approved sparse / botanical visual character.
