# T2 — 重力を入れる（Study: S2）

対象: 実装モデル（モデル非依存）。着手前に STATEMENT → RESEARCH → AGENTS → この文書を読む。
共通規約は [README.md](README.md)。土台は S1（`src/studies/cloud-sculpt/`）— その場の定義と
履歴の背骨をそのまま輸入する。

## 目的

こねると**力学が色で返ってくる**ようにする。自重でどこが苦しいかが見える — それだけ。
これが最初の「力の場」であり、道具が生成機から余白の道具に変わる分水嶺。

**作者裁定（2026-07-04）: 初手は粗いヒューリスティックでよい。早く動くことを優先する。**
本物の FEM は後の段（S3「印刷して壊す」で実物と突き合わせてから育てる）。
ただし AGENTS §1 の不変則どおり、**粗い近似であることを画面に正直に書く**。
分からないものを分かった顔で表示しない — これは省略不可。

## 作るもの

`src/studies/gravity/` に自己完結の Study 一式。S1 のコードは共有してよい
（field.ts / history.ts の import は自由。ただし S1 側を壊さない）。
S1 の画面に機能を足すのではなく、**別 Study として立てる**（比較 > 装飾。
S1 = 力のない世界、S2 = 力のある世界、を並べて観察できることに価値がある）。

### 1. 地面

- 地平面を一枚表示する（y = 0 でよい）。雲は接地して初めて「支えられる」
- 雲全体を地面に降ろす手段を一つ用意する（「接地させる」ボタンで最下点を y=0 に
  スナップする程度でよい。落下アニメーションは不要）

### 2. 苦しさの推定（粗い近似）

方向性の例（技術選定は自由 — AGENTS §2。ただし選んだ式と根拠を README に残す）:

- 球を節点、球同士の重なり（中心間距離 < r₁+r₂）を接続とするグラフを作る
- 接地している球（地面に触れている球）を支持とする
- 各接続について「その接続を通って地面に流れる質量」を数える
  （上に載っている球の体積の合計、経路は最短か全経路等分配の素朴なもので可）
- 苦しさ ∝ 流れる質量 ÷ 接続の断面積（重なり円の面積程度の近似でよい）
- 地面に繋がっていない球（宙に浮いた島）は**最大の苦しさ**として表示する
  （支えが無いものは立てない、を色で言う）

これは梁でも FEM でもない、ただの「力の流れの素描」である。それでよい —
つまんで細くしたら赤くなる、太くしたら青に戻る、という**手応えの向き**が正しければ合格。
量的な正しさは S3 の実物で校正する。

### 3. 余白の色（Katachi の顔 — 慎重に）

- スケールは **青 = 楽 ↔ 赤 = 限界**（AGENTS §5。全 Study 共通、一度決めたら変えない）
- 表示は表面の色（レイマーチのシェーダに球ごとの苦しさを渡して補間）。
  S1 のシェーダは球ごとの uniform 配列を既に持っているので、その拡張が素直
- 中間色・補間の設計は実装者に任せるが、**具体的な色値は README に理由つきで記録**し、
  完了報告で「作者の視覚確認待ち」と明記する（作者は視覚で判断する人。
  色スケールの最終確定は作者の承認事項 — 確定して初めて Library 候補になる）
- 画面のどこかに常設で小さく: 近似の説明（例:「粗い近似: 質量の流れ÷接続断面。
  FEM ではない。実物の保証はしない」）。これが計器の正直さ（RESEARCH §7）

### 4. 手の履歴

- 苦しさの色は**場からの導出物**なので履歴に乗せない（正本 = 場＋手の履歴。表示は導出）
- 履歴に乗るのは操作だけ: 接地させる（例: `snapToGround`）・重力表示の on/off が
  パラメータならその変更。S1 と同じ形式 `[{t, op, args}]`、export→import で同じ形＋同じ色が再現されること

### 5. Study の体裁

- `README.md`（Question/Setup/Observation/Hypothesis/Related/Next）。Question は例えば
  「粗い力の素描でも、手応えの向きは合うか」— 起草してよいが作者の言葉を上書きしない
- `manifest.json`（名前・作成日・パラメータ一覧・revisits）
- 画面に Version と UpdatedAt（ルート共通 UI ルール）
- `index.html` からの入り方は実装者判断（S1 と切り替えられる素朴なリンクで十分。
  凝ったハブ画面は作らない — 道具は研究の堆積物）

## やらないこと

- 本物の FEM・座屈・材料異方性（後の段）。安全率の断言（永久にしない — AGENTS §6）
- 印刷用出力（T3）。育てる手（T6）
- S1 の機能削減や大改造（共有はよいが、S1 単体の完了条件を壊さない）

## 完了条件

1. 雲を接地させると、**太い接続は青く・細い接続は赤く**見える
2. 選択した球をつまんで細くする（S1 の個別半径）と、**その場で色が赤に流れ込む**
3. 宙に浮いた球（どこにも繋がらない島）が最大の苦しさで表示される
4. 近似の説明が画面に常設されている（正直さの担保）
5. 履歴の export→import で同じ形・同じ色が再現される
6. 色値と近似式が README に理由つきで記録され、完了報告に
   「作者の視覚確認待ちの項目」（色スケール・苦しさの見え方）が列挙されている
