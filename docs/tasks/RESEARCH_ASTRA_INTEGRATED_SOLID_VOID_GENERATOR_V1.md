## Core hypothesis

Design one coupled generator in which:

```text
Host-derived interior organization
        ↕
protected / evolving Void network
        ↕
Permanent volumetric growth + History
        ↓
surface emergence events
        ↓
motifs
```

Build direction / printable state acts as a bounded condition on the same Permanent Structure, not as a later independent geometry generator.

The target is **volumetric occupation without visual fill**.

A sparse network should use multiple depths of the Host while still preserving perceptible air, sight-lines, Host legibility, and motif-scale computational specificity.

## Author criterion — perceptual openness

Promote "抜け" to a primary Research criterion.

Do not reduce it to porosity or X/Y/Z ray-through percentage.

Desired condition:

- multiple openings visible from many viewpoints;
- different openings become visible as the viewpoint moves;
- openings overlap, diverge, approach, branch, and visually interweave;
- one opening seen from one side may read as a different spatial relation from another side;
- the result should not be one large cavity or a few simple drilled tunnels;
- motif inclusion must not collapse the openings into dense support / infill appearance.

Use ray-through / visibility statistics only as diagnostics. Do **not** define a fixed numeric pass threshold such as 20%.

The upper-level gate is author-observed **perceptual permeability across multiple views**.

## Solid–Void co-design, not Boolean-only

A protected Void network / Void-Boolean-like construction is explicitly allowed as a Research mechanism, but it is not the sole generator.

Avoid the one-way rule:

```text
predefine Void completely -> structure whatever remains
```

Instead test mutual constraint:

```text
Host-derived growth ↔ protected / evolving Void channels
```

The generator should be able to preserve or reshape channels as growth proceeds, while the Permanent Structure still retains a causal Host-derived history.

## Density criterion

Previous V0 comparison was deliberately material-budget matched and became visually too dense.

For this task, do **not** preserve the old `4500 mm^3 / 512 motif` budget merely for parity.

Use the author's visual reference: approximately the sparseness of the prior **`Internal edges only / diagnostic`** view as the starting artwork-density target.

Important:

- volumetric != dense;
- fewer members may be preferable if they traverse depth meaningfully;
- structure + motifs must remain visually distinct from conventional slicer Support / dense infill;
- motif inclusion is part of the artwork gate, not a downstream decoration check.

The Host remains at **1000% scale** for this Research prototype.

## One authoritative generator + diagnostic variations

Create one underlying algorithm and four outputs. Do not implement four unrelated algorithms.

### BASE — Integrated

Balanced Solid–Void co-design combining:

- Host-derived interior organization;
- volumetric depth crossing;
- emergence-driven motif causality;
- interwoven multi-angle Void preservation;
- bounded lower-to-higher print causality.

### V1 — Void-biased

Same algorithm and primary budgets as BASE.

Change only the weighting / pressure that preserves multi-angle, multi-channel perceptual openness.

Purpose: reveal what stronger Void protection changes.

### V2 — Causal-growth-biased

Same algorithm and primary budgets as BASE.

Strengthen Host -> interior organization -> branch/history -> surface emergence -> motif dependence.

Do not increase motif count merely to make the image more complex.

Purpose: reveal what stronger causal emergence changes.

### V3 — Print-causal-biased

Same algorithm and primary budgets as BASE.

Strengthen bounded already-established lower-to-higher Permanent connectivity / printable-state preference.

Do not turn the result into a generic self-supporting truss or scaffold.

Purpose: reveal what stronger Permanent print-causality changes.

## Evaluation questions

For each output ask:

1. Does Permanent Structure materially traverse multiple Host depths while remaining sparse?
2. From changing viewpoints, do multiple distinct openings appear rather than one generic large cavity?
3. Do the perceived openings change relationships with viewpoint and appear spatially interwoven?
4. Does adding motifs preserve those openings?
5. Does the result avoid slicer-Support / infill / generic truss / Voronoi-foam appearance?
6. Can motif placement be traced to Host-derived growth history?
7. Does stronger Void pressure, causal-growth pressure, or print-causal pressure change the work in an interpretable way?
8. Does print-causality reduce unsupported-island proxies without dominating the artwork?
9. Does the Host remain perceptible without being reduced to a shell trace?
10. Does the result preserve the fine computational specificity valued in A2 while using the volume more deeply?
