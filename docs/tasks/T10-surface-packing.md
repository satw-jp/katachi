# T10 — 表面に詰める（Study: S-skin・地と図の反転）

対象: 実装モデル（モデル非依存）。着手前に STATEMENT → RESEARCH（**v5 の Y7 第二補正と

## 目的（作者の言葉が仕様）

「ある形態の**表面に**ランダムな閉じた平面形状をパッキングする」
「**平面形状が実体で形態が虚になることもあればその逆もある**」

新要素は**実と虚の反転（地と図の裏返し）**: 同じパッキングから二つの作品が出る —
- **プレートが実**: 表面に点在する閉じた形だけが物体になり、形態そのものは印刷されない。
  「体積は無いが、かたちの存在感は残る」の表面版
- **形態が実**: 殻に平面形状の**窓**が開く

## 作るもの

`src/studies/skin/` に自己完結の Study 一式（`skin.html`、ナビリンク、Version/UpdatedAt、
README、manifest）。

### 1. 場の定義

- **ホスト**: S1 の球リスト＋k（既定 grow / S1 レシピ読み込み）
- **殻**: |hostSdf| < 厚み/2 の層（厚みはつまみ — プレートの板厚でもある）
- **パッチ（閉じた平面形状）**: 表面上のアンカー点のまわりの表面領域。
  真円で始めない — 作者は「ランダムな閉じた平面形状」と言っている。素朴な実装案:
  アンカー点の近傍にいくつかの副点を撒き、それらの（表面に沿った近似）距離場の
  smooth-min で輪郭をつくる = ふわふわした不定形の閉領域（2D メタボールの表面版）。
  形の不揃いのつまみ（副点の数・散らばり）を持つ
- **合成（モード切替 — この Study の眼目）**:
  - **プレートが実**: 殻 ∩ パッチ群の和
  - **形態が実（窓）**: 殻 − パッチ群
  - 切替はワンタッチ。同じパッキング結果に対して**両方を行き来できる**こと（地と図の反転を
    手で往復して観察するのがこの Study の体験の核）

### 2. 詰める手（T9 の表面制約版）

- 「詰める」: 表面上にランダムなアンカーを取り（内部サンプル→SDF 勾配で表面へ射影）、
  既存パッチとの間隔（**目地** = パッチ間に残る肉/隙間の最小幅）を守って貪欲に置く
- つまみ: パッチの大きさ下限/上限・形の不揃い・**目地 g**・詰め込みの強さ・シード・殻の厚み
- 履歴 op `packPatches` は**結果（アンカー・副点・サイズ）を引数に持つ**（T9 の流儀）。
  パッチの手動追加・選択削除もできれば望ましい

### 3. 計器

- パッチ数・表面被覆率の粗い推定・最薄の目地（プレート版では逆に**プレート間の最小間隔** —
  分離しているか繋がってしまうかの境目）を表示。mm 換算は書き出し寸法と連動
- プレート版の正直な注意: プレートは互いに**離れている**ので、書き出すと**バラバラの部品**になる
  （それが意図の中心でもある）。連結成分数を表示し、「N 個の分離した部品」と明言する

### 4. 出口

- STL/OBJ 書き出し（buildMeshFromField に合成 SDF を渡す）。水密検査・mm・レシピ対保存は
  いつもどおり。レシピは独自形式（studyId: "skin"）

## やらないこと

## 完了条件

1. 「詰める」で不定形の閉じたパッチが表面に目地を守って詰まる
2. **モード切替で地と図が反転する**: 同じパッキングから「プレートの点在（形態は暗示）」と
   「殻に窓」の両方が出て、ワンタッチで行き来できる
3. プレート版で連結成分数が表示され、「バラバラの部品」であることが明言される
4. STL 書き出しが通る（プレート版は分離部品のまま水密 — 成分ごとに閉じていること。実測を README に）
5. 履歴 export→import で完全再現（packPatches が結果を引数に持つ）
6. 実座標クリック検証・既存7ページの無退行・README（パッチ輪郭の式・被覆率の推定法・実測）・
   manifest・`npm run build` 通過
