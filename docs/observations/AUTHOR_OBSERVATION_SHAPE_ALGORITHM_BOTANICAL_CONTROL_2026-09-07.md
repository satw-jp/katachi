# Author Observation — Shape ↔ Algorithm Botanical Control

Date: 2026-09-07
Owner: Author / Research SOL
Status: AUTHOR OBSERVATION / FUTURE SKIN PARAMETERIZATION INPUT

## Observation

The current D / Integrated direction is artistically promising.

The author sees two simultaneous qualities in the current result:

- the USAGI host shape remains legible;
- the generated structure / motif system also begins to read as plant-like / botanical.

This coexistence is desirable. The future goal is **not** to choose permanently between host-shape fidelity and algorithmic botanical expression.

Instead, SKIN should eventually allow the author to control that balance parametrically.

## Desired author-facing axis

A future high-level control should allow movement along an axis roughly like:

```text
HOST / SHAPE-LED  <-------------------->  ALGORITHM / BOTANICAL-LED
```

At the shape-led end:

- USAGI silhouette / host identity remains stronger;
- emergence and motif distribution stay closer to host-derived shape cues;
- branching / internal organization should not erase the host reading.

At the algorithm-led / botanical end:

- growth history, branching, anastomosis, emergence, motif orientation / variation, and Void-driven organization may become more visually dominant;
- the work may read more like a generated plant-like organism while still retaining a causal relationship to the host;
- botanical appearance should arise from the generator and its history, not from arbitrary decorative scattering.

## Important boundary

This artistic control should remain conceptually separate from fabrication safety.

The author should be able to change shape-vs-algorithm expression without silently disabling print-causality, removable-Support rules, minimum physical dimensions, or other fabrication constraints.

In other words:

```text
AUTHOR EXPRESSION PARAMETERS
    host fidelity / growth expression / motif emergence / Void articulation

            should be separated from

FABRICATION CONSTRAINTS
    print-causality / minimum radius / connectivity / residual Support policy
```

A future implementation may couple them where necessary, but the UI / system should expose when fabrication limits override an artistic request rather than hiding that override.

## Likely decomposed controls behind the high-level axis

Do not implement these yet. They are research / future Production translation candidates only:

- Host attraction / host-fidelity weight;
- interior-growth / history-expression weight;
- branch wandering / curvature / anisotropy;
- anastomosis / reconnection pressure;
- Void protection / Void articulation pressure;
- surface-emergence distance / timing;
- motif orientation inheritance from branch / normal / history;
- motif scale / density / variation;
- silhouette retention / boundary-following pressure.

The author-facing UI may eventually expose one simple macro control first, with these decomposed controls available as Advanced / Lab parameters if needed.

## Current Research implication

For the current Research lane, preserve the present visual direction as a positive reference:

- USAGI remains readable;
- botanical / plant-like organization is beginning to emerge;
- sparse volumetric structure and perceptual openness remain important;
- future printability fixes should not collapse this balance into a generic support lattice or purely shape-tracing shell.

No Production change is authorized by this observation. Use it as design input when the current Research geometry / fabrication system is eventually translated into SKIN.
