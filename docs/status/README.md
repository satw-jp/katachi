# Current Status SSOT — Lane Router

Use [TEAM_PROTOCOL_CORE](../TEAM_PROTOCOL_CORE.md) for common rules. The old [TEAM_REPORTING_RULES](../TEAM_REPORTING_RULES.md) path remains a compatibility entry, not another required read.

Choose by the question or assigned task; do not load the whole table.

| Need | Entry | Boundary |
|---|---|---|
| Author-facing SKIN priorities / selective Research translation | [SKIN_ABC_CURRENT](SKIN_ABC_CURRENT.md) | Does not merge AB/C architectures or automatically authorize Production work |
| Retained AB capability / explicitly assigned AB work | [AB_CURRENT](AB_CURRENT.md) | Preserve accepted checkpoint and evidence |
| C Production / FIELD / explicitly assigned C work | [C_CURRENT](C_CURRENT.md) | Preserve C-specific authority and gates |
| Research Astra Reader | [SKIN_R_CURRENT](SKIN_R_CURRENT.md) | Reader work is not external generator authority |
| Pencil / Wire / Volume authoring | [HANA_CURRENT](HANA_CURRENT.md) | Respect software-versus-device gate separation |
| FKEI Analysis Viewer | [VIEWER_CURRENT](VIEWER_CURRENT.md) | Keep Viewer-only contracts |
| Independent generative ART | [ART_CURRENT](ART_CURRENT.md) | Author artistic judgment controls continuation |
| Hikari | [HIKARI_REFERENCE](../protocol/HIKARI_REFERENCE.md) | Dedicated authority/runtime verification, not another lane's CURRENT |

External Research packages follow their named research task and source authority; do not substitute SKIN_R's Reader status for generator progress.

Each lane owns a stable CURRENT, updated at authorized published checkpoints. CURRENT is a pointer to evidence, not evidence itself. Read its front to find the active task, owner, allowed/protected scope, blocker, and exact next gate. `NONE` is a valid answer; a file's existence is not permission to implement.

Use [CURRENT_FORMAT](../protocol/CURRENT_FORMAT.md) when maintaining status and [the template](_CURRENT_TEMPLATE.md) when creating one. Keep historical details below the front. Do not create a new status report per task or infer local/dirty/unpushed progress from GitHub.
